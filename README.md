# WINTERLIGHT

브랜드: **WINTERLIGHT · 윈터라이트**. 사용자 선택에 따라 화이트·샴페인 골드, 작은 소문자 `winterlight`, 원본 로딩 트리 선을 사용합니다. 로고·탭 아이콘·공유 카드·정적 메타데이터를 함께 맞췄습니다. Sites 버전 46과 [공개 사이트](https://moru-winter-park.vercel.app) 운영 반영을 완료했고 두 주소에서 각각 HTTP 검사 9/9를 통과했습니다. GitHub 소스 동기화만 연결의 쓰기 권한 오류로 남아 있습니다. [변경·검증 기록](docs/winterlight-brand.md).

모루 캐릭터로 돌아다니는 Three.js 겨울 소셜 공간입니다. 중앙 놀이공원과 성, 설산, 온천·료칸, 소원 트리, 별빛 만물관이 독립된 부유섬과 다리로 연결됩니다. 제거한 오로라 식물원·아이스링크·눈썰매·회전컵·범퍼카는 제공하지 않습니다.

최근 변경: [v42 Windows 모션·모바일 지도·불꽃 잔광](docs/platform-motion-v42.md). 움직임 감소에서도 보행과 눈 내림을 유지하고, 명시적인 전체 모션 선택을 적용합니다. 모바일 하단 지도와 직접 설정 버튼, 같은 유리 패널 색상, 짧은 불꽃 잔광을 반영했습니다.

이전 변경: [v41 게스트·모바일·VFX 안정화](docs/stability-v41.md). 원격 이동/정지 보간, 출력 색상·셰이더 사전 준비, 모바일 지도와 커마, 작은 로딩 트리, 음악 중복 전환을 개선했습니다.

## 실행

```sh
npm ci
npm run dev
npm test
npm run build
npm run build:vercel
npm run test:budget
```

`PORT`로 포트를, `LOCAL_DB_PATH`로 테스트용 SQLite 경로를 지정합니다. `PREVIEW_STATIC_DIR=dist`는 작업 소스를 직접 미리 봅니다. `LIVE_RELOAD=1`은 로컬 변경 갱신용이며 배포에는 포함하지 않습니다. 별도 lint/typecheck 명령은 없습니다.

## 플레이와 저장

- PC: 비눗방울을 든 상태에서 E를 누르면 걸으며 계속 붑니다. WASD 이동, Shift 달리기, Space 점프, M 지도, Esc 설정, Enter 채팅. 화면을 시야 조절 모드 또는 마우스 오른쪽 드래그로 시점을 조절합니다. 기본은 일정한 시야이며 R로 기본 시점에 돌아갑니다.
- 모바일: 이동 조이스틱, 달리기 토글, 점프·제동. 시야 조절 모드에서 드래그 회전과 핀치 확대를 사용합니다. 조이스틱 위 지도 아이콘은 모바일에서만 표시됩니다. 첫 터치로 목적지를 선택하고 `이동` 버튼으로 이동합니다.
- 설정은 오른쪽 위 설정 버튼 또는 Esc, 지도는 M 또는 설정 → 지도에서 엽니다. 소유자의 운영 메뉴는 설정 → 초대 → 관리입니다.
- 관리자의 유효한 초대 링크로 회원가입 없이 입장합니다. 초대가 달라도 모두 같은 월드이며, 서버가 확인한 유일한 관리자만 링크 발급·폐기와 운영 기능을 사용할 수 있습니다.
- 누구나 불꽃놀이를 신청할 수 있습니다. 10초 예고 뒤 같은 공연을 함께 보고 공연 종료 후 3분 동안 다음 신청을 기다립니다. 일반 공지·이벤트 관리 기능은 제공하지 않습니다.
- 내 지식집에서 푼 문제·맞힌 문제·담은 지식과 당시 해설·출처를 다시 볼 수 있습니다. 기존 익명 세션으로 저장하며 기기 간 계정 복구는 제공하지 않습니다.
- 료칸 오마카세는 세 좌석 중 원하는 자리에 앉으면 셰프가 순서대로 한 접시를 대접합니다. 의자 표면 또는 좌석 버튼으로 고르며 이미 찬 자리는 다른 자리로 자동 배정하지 않습니다. 자세한 서버 계약은 [오마카세](docs/ryokan-service.md)에 있습니다.
- 닉네임은 보이는 글자 10자 이내입니다. 닉네임·커스터마이징, 채팅, 2인 벤치·탑승, 소원·트리 장식은 서버와 동기화합니다. 현재 방식은 HTTP polling이며 방 정원은 12명입니다.
- 익명 세션 쿠키는 30일간 유지됩니다. 계정 복구 시스템은 아니므로 쿠키를 지우면 이전 작성자 권한을 복구할 수 없습니다.
- 새 소원은 현재 공간 방문자에게 공개됩니다. 과거 비공개 소원의 공개 범위를 바꾸지 않습니다. 다른 초대 공간에 소원을 공개하지 않습니다.
- 트리 꾸미기는 하단 도크에서 반복할 수 있으며 닫으면 추가 프레이밍만 끝내고 사용자가 정한 시야를 유지합니다. 공개 소원 목록은 별도로 열어 둔 채 이동할 수 있습니다. 소원 우체국은 소원 작성 전용입니다. 리프트는 즉시 출발하며 초급 26초, 정상 36초입니다. 스키·놀이시설 이용을 마치면 전용 장비·UI·소리를 정리하고 사용자 카메라 설정을 유지합니다.
- 조명색은 개인 화면에 적용됩니다. 가로등 전구, 제한된 실제 광원과 눈 위의 빛이 함께 바뀌며 성·트리 고유 조명은 유지합니다.

## 지도·월드 제작

`dist/region-layout.js`의 구역·앵커를 지형, 다리, 지도 마커와 안전 도착점이 공유합니다. 다리는 양쪽에 직선 진입 공간을 확보하고 산책로는 기존의 부드러운 눈길 재질을 사용합니다.

좌표를 바꾼 뒤 `npm run build`로 보행 경로를 굽고, QA 서버를 실행한 상태에서 `npm run build:map`으로 실제 월드의 정적 지도 이미지를 다시 생성합니다. 지도는 WebP 이미지와 독립된 SVG 마커를 사용하며 두 번째 실시간 3D 렌더러를 실행하지 않습니다. 브라우저 제작 도구의 경로는 [v32 개발 기록](docs/winter-world-v32.md)에 있습니다.

## 음악과 효과음

실제 음원 파일 11곡을 제공합니다. 앞쪽 순서는 Cinematic Christmas Piano Strings Bells → Winter Waltz → Winter Jazz → Ethereal Winter Ballet Instrumental 02 → Wonderful Night입니다. 나머지 기존 곡과 이전·다음·반복·셔플·크로스페이드를 유지합니다.

출처와 권리는 [음원 라이선스](dist/audio/LICENSE.txt), [음원 확보 기록](docs/audio-winter-v3.md), [추가 3곡 기록](docs/gameplay-v31.md)을 참고하세요. 배경음악과 별개로 환경음·행동 효과음은 Web Audio 합성음을 사용합니다. 현장 녹음으로 표기하지 않습니다.

## 서버와 배포

- Sites: Worker와 기존 D1 DB를 사용합니다.
- Vercel: 정적 게임과 `/api` 프록시를 제공하며 같은 Sites 서버에 연결합니다. 주소가 달라도 같은 공간으로 접속합니다.
- 관리자 인증과 초대 공간 생성은 서버에서 검증합니다. 클라이언트만으로 방을 만든 것처럼 표시하지 않습니다.
- 선택적 AI는 서버 설정 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 사용합니다. 개발 중인 v35에서는 설정 → 소리 → 추천 및 접근성의 명시적 동의와 직접 요청을 요구합니다. 음악 추천과 전시 카드는 등록된 콘텐츠만 선택하며, 실패 시 기본 콘텐츠임을 표시합니다. 별도 AI 길 안내 캐릭터는 없습니다.
- 비밀 키, `.env.local`, 로컬 DB와 빌드 임시 파일은 저장소에 포함하지 않습니다.

현재 변경·검증은 [개발 기록](docs/DEVELOPMENT_LOG.md), [v32 상세](docs/winter-world-v32.md), [변경 이력](CHANGELOG.md)에 기록합니다. 과거 문서는 당시 상태를 나타내며 최신 구현 설명을 대신하지 않습니다.
