# 모루 겨울공원

Three.js 기반 겨울 소셜 공간. 기존 스키·리프트·온천·공동 트리를 유지하면서 놀이기구, 소원 우체국, 아이스링크와 공간 AI를 확장했습니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
npm run build:vercel
```

`PORT`로 미리보기 포트를 지정할 수 있습니다. 로컬 서버는 `.env.local`을 읽고 SQLite에 마이그레이션을 적용합니다. 별도 lint/typecheck 명령은 없습니다.

## 참여와 저장

- 공개 공간은 계정 없이 접속합니다. 기존 비밀번호 초대 공간도 유지합니다.
- 지도(M), 채팅(Enter), 커스터마이징은 모든 방문자가 사용합니다.
- 모바일은 조이스틱, 점프/제동, 화면 회전·핀치 확대를 사용합니다.
- 익명 세션 쿠키는 30일간 유지됩니다. 비공개 소원은 같은 브라우저의 작성자만 조회합니다. 쿠키를 삭제하면 작성자 식별이 복구되지 않습니다.
- 채팅은 화면에서 약 6.5초 후 사라지고, 펼친 채팅창은 최근 10분/50개 이내 기록을 보여줍니다. 서버의 오래된 메시지는 활동 요청 시 정리합니다.
- 장식·소원·신고와 관리 설정은 서버 DB에 저장합니다. 관리 권한은 Sites의 인증된 사용자 정보로 확인합니다.

## AI

서버의 `OPENAI_API_KEY`, `OPENAI_MODEL`을 설정합니다. 기본 구성은 `gpt-4.1-mini`이며 키는 브라우저로 전달하지 않습니다. 로컬 `.env.local`과 배포 서버의 비밀 설정은 별개입니다.

공간 안내, 장식 추천, 검증된 퀴즈 해설과 온실 조명 선택에 연결합니다. 실제 장소·장식·색상 목록에 맞는 구조화 응답만 적용합니다. 8초 제한과 대체 응답이 있으며 방문자당 분당 4회, 하루 20회, 전체 하루 100회의 AI 호출 제한을 둡니다. 같은 질문은 5분간 메모리에 캐시합니다. 실패 요청도 보수적으로 사용량에 포함합니다.

안내 질문·추천을 요청한 소원 내용은 OpenAI에 전송됩니다. 비공개 소원도 장식 추천을 누르면 전송되므로 입력 화면에 알립니다. API 응답 저장은 `store:false`로 요청합니다.

## 배포

- Sites: Worker 및 정적 자산과 기존 D1 DB를 사용합니다. 런타임 비밀 설정 변경은 새 배포 후 반영됩니다.
- Vercel: 정적 게임과 `/api` 프록시를 배포합니다. 요청은 동일한 Sites 서버로 전달되어 양쪽 방문자가 같은 공간을 공유합니다.
- 관리자 로그인·초대 생성은 기존 Sites 인증 주소에서 진행합니다.
- 비밀 키·로컬 DB·빌드 산출물은 저장소에서 제외합니다.

## 콘텐츠와 음악

출처를 확인한 한국어 퀴즈 35개를 7개 분야로 나누어 서울 날짜 기준 하루 7개씩 순환합니다. 실시간 외부 퀴즈 API가 아닙니다. 로컬 캐시·예비 문제와 관리자 수정/출제 중지를 지원합니다.

현재 재생 가능한 음악은 Scott Buckley의 First Snow, Moonlight 두 곡(CC BY 4.0)입니다. 호두까기 인형 녹음 세 곡은 제거했습니다. 출처는 [음원 라이선스](dist/audio/LICENSE.txt)에 있습니다. 요청한 Pixabay 6곡과 녹음 효과음은 다운로드가 완료되지 않아 포함하지 않았습니다. [검토 결과](docs/audio-source-review.md)를 참고하세요.

환경음·행동 효과음은 Web Audio로 합성합니다. 음악 크로스페이드/셔플/반복과 독립 볼륨, 거리·방향 기반 환경음, 지면별 발소리와 속도 기반 스키 소리를 제공합니다. 실제 현장 녹음이라고 표시하지 않습니다.

검증 범위와 미완료 항목은 [출시 점검](qa/metaverse-v2.md), 추가 지역 설계는 [확장 계획](docs/world-expansion.md)에 기록합니다.
