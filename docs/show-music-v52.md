## 이용 조건 확인

확인한 [정식 약관](https://pixabay.com/service/terms/)은 2026-10-20 갱신본이다. Content License는 금지된 이용을 제외하고 상업·비상업적 이용과 수정·각색을 허용하며, 음원 자체를 독립 상품이나 파일로 재배포하는 것은 금지한다. WINTERLIGHT의 독자적인 3D 공연에 결합하는 사용은 더 큰 창작물의 일부라는 해석에 부합한다. 이는 공식 문서에 근거한 적용 판단이며, 개별 파일의 다운로드 증명을 대신하지 않는다. 원본의 저작자·소유권을 WINTERLIGHT로 표시하지 않는다.

[공식 FAQ](https://pixabay.com/service/faq/)는 Content ID 등록곡에도 라이선스가 적용되지만 녹화 영상을 다른 플랫폼에 게시하면 자동 권리 주장이 생길 수 있다고 설명한다. 등록곡의 다운로드 증명서를 보관한다. 게임에서 음원을 재판매하거나 다운로드 상품으로 제공하지 않는다.

## 실제 확보 과정

공식 웹 페이지의 공개 메타데이터는 웹 도구로 확인했다. 처음 로컬 Chrome에서 두 공식 URL을 방문했을 때는 모두 HTTP 403과 Cloudflare 보안 확인 화면이 표시되어 다운로드하지 못했다. 보안 확인을 우회하지 않았다.

이후 사용자가 Downloads의 두 실제 원본 파일을 제공했다. `levvvv-happy-and-magical-dynamic-290346.mp3`와 `royaltyfreemusicstudio-joyful-piano-orchestra-462200.mp3`를 그대로 복사했으며 원본과 배포 소스의 SHA-256 일치를 확인했다. 사이트에 표시된 곡명·제작자·라이선스와 사용자 제공 파일명을 대조했다. 별도의 Content ID 다운로드 증명서는 제공되지 않았다. 기록 영상의 자동 권리 주장에 대비한 증명서 보관은 미확인이다.

## 음향 측정과 타임라인 후보

[전체 측정 JSON](show-music-analysis-v52.json)에 디코딩 길이, 파일 해시, 템포 후보, 강한 attack 시각, 0.5초 RMS 및 flux, 악구 경계 후보를 기록했다.

- 방법: 44.1 kHz 브라우저 디코딩 후 분석만 mono 22.05 kHz로 축소. Hann STFT 1024 samples / hop 256. 양의 log spectral flux에서 국소 평균을 뺀 attack을 추출하고 자기상관·정밀 템포 격자 검색을 수행했다. 분석용 축소이며 제공·재생 원본은 변환하지 않았다.
- A: 추정 **128 BPM**, 첫 beat 격자 offset **0.024초**. 분석 대상 강한 attack 177개 중 173개가 격자 ±35ms에 들어왔다. 큰 스펙트럼 변화 후보 17.5 / 28.5 / 43.5 / 58.5 / 73.5 / 88.5초, 107.5초에서 큰 에너지 감소가 있다.
- B: 추정 **127 BPM**, beat offset **0.056초**. 강한 attack 175개 중 147개가 격자 ±35ms에 들어왔다. 주요 변화 후보 13.5 / 29 / 44 / 62 / 74.5 / 91 / 107.5 / 122초다. A와 다른 구간 길이·악기 에너지 분포를 보인다.
- RMS 0.002 기준의 유의 음량 범위는 A 1.161~109.691초, B 0.035~124.854초다. 이 값으로 무음을 잘라내지 않는다.

이는 실제 파일에서 측정한 **기계적 후보**다. 사람이 전곡을 청취하여 확정한 악구·강세 악보라고 표현하지 않는다. 구간명은 공연 디자인용 제안이며 곡의 공식 악장명이 아니다. 균등한 시간 확대 대신 각 파일의 측정 경계와 개별 attack 시각을 타임라인 설계에 이용할 수 있다.

## 공연 통합 검사

1. 원본 파일 확보·동일 해시 확인 완료. 별도 Content ID 증명서는 미제공이다.
2. SHA-256·파일 크기·실제 디코딩 길이·샘플 수·제공 날짜 기록 완료.
3. 곡별 음향 분석 완료. 해당 측정에 맞춘 공연 큐와 두 곡의 실제 완곡 재생 검증을 통과했다. 침묵 제거·속도 변경·반복은 하지 않는다.
4. 서버가 선택한 음악 ID와 길이, 시작 시각, 타임라인 버전 및 시드를 모든 클라이언트가 공유하는지 검증했다.
5. 완곡 재생, 중간 입장 위치 보정, 음소거·오디오 활성화, 종료 시각 기준 15분 제한을 실제 원본으로 검증했다.

이 문서는 출처·원본 확보·음향 측정의 기록이다. 공연 통합·멀티플레이 재생·운영 배포 결과는 최종 검증 문서에 별도로 기록한다.
