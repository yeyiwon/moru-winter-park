# v56 — 부드러운 공연 조명과 몽실한 안내자

2026-11-20 최종 추가 요청을 반영한다. 단발과 양쪽 동시 곡선 이동 후 반대쪽에서 터지는 불꽃, 사진처럼 퍼지는 상승 발사, 짧은 지상 분수형 불꽃을 함께 구성한다. v55 천문대·음악·설정 안내를 포함한다.

## 변경

- 곡선 불꽃은 3.1초 동안 좌우를 번갈아 건너며 끝점 높이 80m에서 실제 꽃 모양으로 터진다. 양쪽 동시 출발도 섞는다. 일반 공중 폭발 사이에 6갈래 상승 발사와 양쪽의 짧은 지상 분수를 넣었다.
- 공연 시드에 따라 세 가지 색 조합·패턴 순서·발사 방향을 선택한다. 서버가 전달한 동일한 시드·음악 시각을 사용하므로 모든 게스트의 연출이 일치한다. 매회 다른 스타일을 무조건 보장하는 방식은 아니며 음악도 기존 서버 랜덤 선택을 유지한다.
- 위로 퍼지는 6발은 동시 폭발과 좌→우/우→좌 0.16초 간격 연속 발사를 순환한다. 비행시간을 동일하게 두어 발사와 폭발 모두 순서를 지킨다. 소형 탄 대신 더 넓게 퍼지는 peony 형태로 바꾸었다.
- 동물 패턴은 최종 요청대로 제거했다. 하트는 하나 또는 세 개가 실제 불꽃처럼 계속 팽창하고 중력으로 떨어진다. 피날레 마지막 악센트에서만 **HAVE A / GOOD DAY** 두 줄이 등장하고, 짧게 읽힌 후 불티마다 조금씩 다른 시점부터 떨어져 흩어진다. 글자·하트는 OS 글꼴에 의존하지 않는 고정 점 배열이다.
- 포인터형 레이저를 전부 넓고 부드러운 서치라이트·빛의 부채로 교체했다. 바닥 광량을 낮추고 빛 가장자리·끝부분을 점진적으로 흐리게 하여 갑자기 끊겨 보이는 경계를 줄였다. 실제 SpotLight 2개가 성 표면을 비춘다. 그림자는 추가하지 않고 조명은 계속 재사용한다. 기존 10개 건축 구역의 표면 프로젝션에는 이동하는 빛 띠와 반짝임을 추가해 돌의 기본 명암을 유지한다.
- 공연 알림의 빈 카운트다운 요소를 숨겨 텍스트 좌우 여백을 맞췄다.
- 다음 신청 대기시간은 공연 종료 후 15분에서 **5분**으로 줄였다. Love / Wedding Entrance 완곡 길이는 유지한다. 저장된 이전 15분 예약도 읽기와 원자적 서버 신청 양쪽에서 5분으로 정규화한다. 진행 중 신청 병합과 관리자 권한 경계는 보존한다.
- 기존 24개 입자 슬롯(최대 51,840개 점)·단일 입자 배치에 궤적을 통합한다. 곡선 끝점의 폭발도 같은 버퍼를 사용한다. 그림자 없는 실제 SpotLight 2개를 재사용하며 프레임별 네트워크 전송·production dependency는 추가하지 않는다.

## 운영에서 추가로 확인한 출입 오류

v55 실제 운영 반복 출입 중 입장은 200이지만 직후 나가기는 409가 되는 현상을 재현했다. HTTP 서버는 실내 좌표를 저장했지만 `pose_at`은 예전 값이어서 실시간 서버가 최신 실외 패킷보다 오래된 checkpoint로 판단해 무시했다.

출입 시 위치 시각·속도를 함께 갱신하고, 서버가 인증·검증한 이동만 `relocate`로 전달한다. 이 메시지는 기존 서명된 서버 RPC에서만 처리한다. 일반 클라이언트의 이동 권한은 그대로 제한하며, 늦게 도착한 실외 위치와 오래된 일반 checkpoint가 확정 입장을 되돌릴 수 없도록 했다. 실시간 서버를 먼저 갱신하여 새 동작을 이해하게 한 뒤 API·화면을 배포한다.

## NPC와 손폭죽

- 천문대의 인사 버튼과 설명 패널을 제거하고 흰 실험복·명찰·민트색 플라스크를 든 작은 과학자로 교체한다. 의상은 NPC 전용 지오메트리이며 사용자 커스터마이징 목록에는 추가하지 않는다.
- 광장은 털실 모자와 목도리를 두른 몽실한 안내자로 교체한다. 근처에서 불꽃놀이 안내 문구와 신청 버튼을 함께 보여준다. 스파클러 안내·인사 버튼은 없다. 활동 탭과 같은 신청 함수·진행 상태·실패 안내·쿨다운을 공유한다. 일반 게스트 권한을 유지한다.
- 트리 안내자는 머리의 빛나는 별·작은 망토·손에 든 장식 구슬로 구분한다. 가까이에서 소원/꾸미기 문구만 6초 표시하고 멀어졌다 돌아올 때 재표시한다.
- NPC 배치와 충돌은 `park-guide-layout.js`를 공유하며, 원거리·실내에서는 바깥 NPC를 숨기고 털 밀도를 품질 단계에 맞춘다.
- 손폭죽은 GPU 입자 한 배치로 발광 중심·짧은 불티 꼬리·소량의 푸른 반짝임을 표시한다. 본인 289개 점, 원격 121개 점으로 고정하고 추가 동적 조명은 없다. reduced motion/flash는 잔잔한 중심광만 남긴다.
