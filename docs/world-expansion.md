# 추가 지역 설계

현재 실제 이용 가능한 추가 지역은 겨울 축제 섬(회전 컵·범퍼카·기차), 소원 우체국과 아이스링크입니다. 기존 광장에서 저녁 매시 첫 2분 동안 트리 조명 이벤트를 표시합니다. 별도의 녹음 공연장은 아직 없습니다.

## 별빛 천문대 — 미구현

기존 스키장 정상 대기 공간에서 경사진 보행길로 연결하는 높은 전망대를 검토합니다. 리프트 하차·스키 출발·화장실 동선을 침범하지 않는 위치를 먼저 정하고, 현재 지형에서 시야 검증 후 좌표를 확정합니다. 망원경은 실제 겨울 별자리 안내와 하늘 관찰 카메라로 이어져야 하며 가짜 관찰 버튼을 만들지 않습니다. 플랫폼 경사/난간/낙하 방지 충돌과 모바일 회전 범위를 함께 검증합니다.

## 비밀 동굴 — 미구현

스키 슬로프 출구와 분리된 설산의 보행 구간에 입구를 둘 계획입니다. 현재 동선을 막는 바위나 슬로프 충돌을 늘리지 않으며, 진입 전후 카메라 전환·실내 천장 충돌·되돌아오는 경로를 먼저 확인합니다. 작은 얼음빛 탐험 경로와 둘이 누르는 빛 장치로 기존 협동 체험을 확장할 수 있습니다. 현재 지도나 안내 AI에는 없는 지역을 노출하지 않습니다.

## 배치·성능 조건

각 지역은 `layout`의 목적지/지형/충돌, 월드 메시, 실제 행동 제어, 서버 위치 범위, 지도·안내 목록을 같은 변경에서 연결해야 합니다. 현재 월드 554 mesh / 175 material / 약 407만 geometry triangles이며, 온천 실제 브라우저 샘플은 약 39fps입니다. 다음 확장은 외형을 추가하기 전에 식생/원경 LOD와 인스턴싱을 개선하고 실제 모바일 성능을 측정해야 합니다. Blender/GLB 자산을 사용할 경우 출처·라이선스, 압축, 충돌 대체 메시와 로딩 상태까지 포함합니다. 이 문서는 구현 완료 보고가 아닙니다.
