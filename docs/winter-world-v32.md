# v32 — 다섯 섬, 동선과 카메라 정비

## 적용 기준

2026-11-18 최신 요청은 **놀이공원·스키장·온천·소원 트리·별빛 만물관만 유지**하는 것이다. 앞선 아이스링크 재배치 요청은 폐기했다. 오로라 식물원, 회전컵, 범퍼카, 눈썰매, 아이스링크는 다시 생성하지 않는다. 소원·닉네임·초대·멀티플레이 데이터는 초기화하지 않는다.

## 원인과 수정

- 하단 스키 자국: 산을 월드 Z축으로 90m 이동한 뒤 자국 생성 판정은 예전 중심 `z=-260`에 남았다. `ski-trails.js`가 `resort-layout.js`의 실제 산 중심과 반경을 사용하도록 수정했다. 다섯 코스의 출발부터 하단 감속 구간까지 자국이 생성되는 회귀 검사를 추가했다.
- 슬로프의 벽과 단차: 작은 예전 시연 지형을 확대하고 각각의 코스를 덮어쓰면서 경계가 끊겼다. 연속적인 산 능선과 두 하부 계곡, 동쪽 우회 코스, 한 하단 감속 구간으로 재편했다. 겹친 코스의 중심 순서 대신 실제 왼쪽 경계와 합쳐진 오른쪽 경계로 지형을 연결한다. 길이 다른 코스가 같은 높이에서 합류하도록 했다.
- 실제 스키장 참고: [Niseko United 공식 코스 지도](https://www.niseko.ne.jp/en/map/)의 상부·하부 연결과 우회 코스를 참고한 축소 게임 지형이다. 실측 복제나 실제 리조트의 난이도 인증을 의미하지 않는다.
- 정상 환승: 다음 경로 위에 떨어졌던 가로등 X 오프셋을 제거하고 각 경로의 수직 방향 바깥으로 배치했다. 전 구간의 캐릭터 어깨·머리 높이를 실제 메시 Raycast로 검사한다.
- 리프트 지연: 서버가 출발 시간을 `now+4000`으로 예약했다. 서버 승인 즉시 출발하며 1.5초 이내 두 번째 탑승자는 같은 출발 시각을 공유한다. 기본 리프트 45→32초, 상부 28→18초. 보이는 빈 의자 순환 속도도 같은 데이터에 맞춘다.
- 카메라: 보행 중 장애물로 카메라가 가까워지면 실제 캐릭터 위치를 중심으로 시선을 보정한다. 리프트 시작 시 155도 안팎의 강제 방향 전환을 없애고 현재 각도를 유지한다. 기본 거리 PC 24m/모바일 28m, 사용자 조절 14~38m. 트리 비행 이벤트는 카메라를 변경하지 않는다. 트리 열기 시 저장한 시점은 사용자가 드래그해도 남고, 명시적 닫기에서 복원한다. 장식은 2.8초 곡선 비행과 작은 흔들림을 사용한다.
- 공개 소원: 신규 소원은 현재 방에 공개하며 공개 여부 선택지를 제거했다. 예전 비공개 소원은 공개로 바꾸지 않는다. 공개 목록은 작성창과 다른 비모달 패널로 분리해 이동·꾸미기 중에도 열어 둘 수 있다.

| 별빛 만물관 | -148,18 | -102,-18 | 29,27 |

온천·만물관은 좌우 같은 거리와 앞뒤 축, 트리는 중앙 앞쪽 축에 놓인다. 관람차 옆의 불필요한 서쪽 설원을 줄이고 솜사탕 부스를 (-77,-15)에서 (-50,11)로 옮겼다. 건물 입장 좌표, 충돌, 지도와 다리는 공통 Region 데이터에서 계산한다.

다리: 놀이공원↔스키장 / 놀이공원↔트리 / 놀이공원↔온천 / 스키장↔온천 / 놀이공원↔만물관. 모든 다리는 양 끝 6m 직선 진입 공간을 갖는다. 아이스링크 연결 2개는 완전히 제거했다. 보행 경로는 기존 부드러운 눈길 재질을 사용하며 굽기 결과 16개 경로다. 산 아래 나무 배치는 같은 경로 데이터를 읽어 보행로 폭과 수관 여유를 확보한다.

## 지도 제작과 UI

`dist/region-layout.js` → 지형·시설 생성 → `scripts/render-world-map.mjs` → `dist/textures/winter-world-map.webp` + `dist/map-atlas.js`.

로컬 QA 서버에서 실제 월드를 한 번 오프라인 렌더링한다. 산의 지도상 Z 압축은 이미지와 마커가 같은 warp를 사용한다. 실행 중 지도는 1600×1400 WebP와 Canvas/SVG 마커만 사용한다. 별도 실시간 Three.js 렌더러를 추가하지 않았다. 새 좌표를 반영하려면 경로를 굽고 지도 이미지를 다시 생성해야 한다.

지도는 기본 1.35배 확대, 전체 보기 버튼은 1배. PC 호버/클릭과 모바일 첫 터치 선택/재터치 이동을 유지한다. 아이콘은 다섯 장소만 표시한다. 가장자리 마커의 장소 이름은 안쪽으로 정렬해 모바일 잘림을 방지한다.

## 나머지 누적 변경

- 개인 조명 테마를 전구·실제 광원·눈 위 빛에 연결. 원거리 장식은 계속 발광하고 실제 동적 광원은 풀 예산 안에서 선택한다.
- Loading…, Esc 설정, 모바일 달리기, 설정 고정 크기와 투명 선택 스타일, 닉네임·초대·관리 정보 구조 정리.
- 검정 털, 눈·안경·왕관 수정, 솜사탕 휴대. 솜사탕이 실제 목적지 목록에서 필터링되던 오류도 수정.
- 큰 탕의 접근 구간 확대, 료칸 주방장, 투명 수족관·물고기 자세, 천문관 실내 장식 개선.
- 음악 11곡 유지, 요청한 첫 다섯 곡 순서 반영. 음원 권리는 별도 음악 문서를 따른다.

- 다섯 구역·충돌·지도·우체국 집중 검사: 19개 통과 (`/tmp/five-region-tests2.txt`).
- 스키·자국·리프트 동기화·비행·지도 집중 검사: 33개 통과 (`/tmp/new-routes-tests3.txt`, 최종 섬 축소 전).
- 정상 실제 메시/캐릭터 장비 검사: 16개 통과 (`/tmp/scene-new.txt`, 최종 섬 축소 전).
- 전체 자동 검사: **304/304 통과** (`node --experimental-vm-modules --test --test-concurrency=2 tests/*.test.mjs`). 지도 툴팁 수정 후 지도·소원 UI 집중 검사 8/8 통과.
- PC/Chrome 모바일 에뮬레이션에서 다섯 다리 이동 **10/10 완료**, 충돌·높이 오류 및 JavaScript 오류 없음. `qa/browser-v32/layout/verification.json`.
- 넓은 데스크톱·노트북·태블릿·모바일·작은 모바일·가로 화면의 색상 선택 및 소원 입력 정렬 검사 통과.
- Worker/Vercel 빌드와 파일 크기 예산 통과: 총 22,109,163 bytes, JS/CSS gzip 904,486 bytes. 이는 FPS 측정이 아니다.
