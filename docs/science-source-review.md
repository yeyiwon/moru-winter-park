## 검토 범위

- 원 출처의 해당 설명을 직접 열어 보거나 공식 사이트의 검색 인덱스 본문으로 대조했다. `source-checked`는 이 사실 대조를 뜻하며 독립 전문가 심사를 뜻하지 않는다.
- 문제 상황, 선택지, 해설, 적용 문제는 독자적으로 작성한 학습용 구성이다. 출처의 문제나 그림을 복제하지 않았다. 실험 상황과 수치는 실제 관측 데이터라고 표시하지 않는다.
- 새 8개는 서로 다른 원리를 다룬다. 각 항목은 조건, 단계별 힌트, 핵심 해설, 3단계 상세 해설, 선택지별 이유, 새로운 상황의 적용 문제, 한계와 출처를 포함한다.
- 사실 판단 문항의 정답은 제시된 조건에서 가장 타당한 선택지다. 생태계·실험 설계 문항은 제한된 관찰만으로 모든 원인을 확정하지 않도록 문구를 제한했다.

## 접근 및 편집 주의 사항

- USGS의 응결·증발 페이지는 재접속 시 JavaScript 확인 화면이 나타났다. 공식 USGS URL의 검색 인덱스 본문에서 찬 컵의 응결, 끓는점 아래 증발, 소금물 증발 후 소금 잔류에 관한 구간을 별도로 대조했다. 원 URL은 정상 공식 출처로 유지했다.
- NASA Cosmicopia 보관 문서는 보온병 설명이 있으나 본문 일부에 오래된 수치와 단순화가 있어 sci11의 출처를 현재 OpenStax 물리 교재의 해당 절과 보온병 도해로 교체했다. 보관 문서의 우주 나이 수치는 사용하지 않았다.
- sci07의 기존 제목은 얼음의 부력과 연못의 동결 순서를 혼동할 수 있어 “얼음은 왜 물 위에 뜰까”로 바꾸고, 연못 설명에는 담수의 약 4°C 최대 밀도와 표면 냉각을 보완했다.
- sci08은 USGS의 염분·밀도 설명에 더해 아르키메데스 원리의 직접 근거를 추가했다.
- sci19의 출처 locator에서 원문에 없는 “Apparent depth” 절 제목을 제거했다. 물속 물체의 겉보기 위치를 설명한 본문과 Figure 25.10을 사용한다.
- sci20은 UL Research Institutes의 전기화학 에너지 설명과 NASA 교육 자료 p.6의 에너지 전환 설명을 사용한다. 전자가 소모·소멸한다는 설명으로 확장하지 않는다.
- 후보였던 energy.gov의 접근 불가 URL 및 Utah 자료는 최종 출처에서 제외했다.
- OpenStax는 현재 페이지에 이용 조건을 표시한다. 이 묶음은 보편적 과학 사실을 확인하는 출처로 링크하며 원문의 표현·도해·평가 문항을 가져오지 않는다. 향후 원문·그림 재사용이나 상업적 재배포 시 해당 자산의 조건을 별도로 확인해야 한다.
