# v38 성능 측정

Mac Apple M2, Chrome 157, 같은 격리 로컬 서버와 게스트 방. PC 1280×800 / DPR 1, 모바일 에뮬레이션 390×844 / 기기 DPR 3 / 렌더 DPR 1.25. 비교 시 수동 high, 동일 production 변환, 같은 GPU query와 장면 순서, 각 6초 표본을 사용한다. 이전은 운영 `0720494`, 이후는 최종 v38 코드다. 자동 품질·DPR 변화의 영향을 제거하기 위한 제한된 비교이며 실물 휴대폰 결과가 아니다.

## 한계

- 짧은 단일 측정이며 OS 부하와 shader cache에 영향을 받는다. FPS가 비슷한 장면에서도 높은 선명도와 하위 프레임을 함께 본다.
- 초기 WebGL/큰 월드 생성은 메인 스레드에서 실행되는 구간이 남아 있다. 로딩 재시도·timeout 정합성 개선이 초기화 전체의 비동기화를 뜻하지 않는다.
- 실물 iOS Safari/Android GPU, 발열·배터리·30분 이상 안정성 UNKNOWN.
- 기존 outdoor 영역의 완전한 자산 streaming은 미구현이다. 실내 lazy loading/해제, 공간별 컬링과 LOD를 사용한다.
