# 지식 연구소 · 기존 판타지 세계를 다듬는 기준

2026-11-14. 이번 수정은 v7의 일곱 섬과 놀이공원을 기준으로 한다. 앞선 v8의 두 테라스 캠퍼스가 장소의 개성을 없앤 문제를 되풀이하지 않는다.

## 관찰과 원인

- 기존 화면에서 확인: 성·관람차·회전목마라는 기억에 남는 중심 구도는 유지할 가치가 있다. 캐릭터 표면의 점묘, 서로 다른 수관 조형, 반복되는 화단과 장식은 시선을 분산했다.
- 코드에서 확인: 개별 털과 고주파 표면, 나무마다 수백 개 잎 조각, 두 별도 장면 함수의 서로 다른 재질 규칙. 성 양옆의 실제 벽보다 큰 사각 충돌 범위가 뒤편 빈 공간까지 막았다.
- 실행으로 확인할 사항: 실제 WebGL 조명·투명도 정렬, 카메라 가림과 조작 감각, 모바일 터치·글자 크기·프레임 시간. 자동 경로 검사와 오프라인 자산 렌더만으로 이 항목을 통과로 표시하지 않는다.

## 전체에 적용한 규칙

1. 색: 깊은 밤 남색, 절제된 보라·회청 석재, 무채도에 가까운 식생. 따뜻한 창과 황동 조명이 장소를 구별하고 밝은 캐릭터가 전경에서 읽힌다.
2. 재질: 석재와 목재는 거칠게, 지붕과 황동은 둔한 금속, 유리와 눈에 제한된 반사. 캐릭터에는 고주파 텍스처·노이즈·독립 털 메시를 쓰지 않는다.
3. 형태: 둥근 아치, 곡선 첨탑, 두께와 모서리 마감을 가진 구조. 첨탑의 금속 이음도 지붕 곡률을 따른다. 상점 창은 발광 직사각형 대신 틀과 카운터를 가진 창으로 정리한다.
4. 식생: 연결된 줄기·가지와 큰 곡면 수관 3개를 하나의 수형으로 구성한다. 높이·방향·군집 크기를 절제해 바꾸고, 보행로와 주요 건물 앞은 비운다. 무작위 풀이나 삼각형 잎 군집을 추가하지 않는다.
5. 건축: 관측 돔·저울 기록원·거울 숲·온실·리라 극장·시계 항구의 서로 다른 실루엣을 보존한다. 공통 곡률·석재·황동과 낮은 식재가 세계를 묶는다.
6. 빛: 차가운 주광과 따뜻한 국소광. 랜턴·별·점광 장식 수를 줄이고 형상을 블룸으로 가리지 않는다. 조명 색과 밝기는 사용자 설정으로 유지한다.
7. 캐릭터: 둥근 연속 곡면, 작은 콩눈과 눈꺼풀, 두 발. 이동 거리 기반 걸음·회전 보간·착지 탄성에 지지 발 접지 보정을 적용한다.
8. 화면: 탐험에서는 작은 메뉴와 가까운 전시물의 질문만 보인다. 학습실에서는 장면 갱신을 멈추고 본문·선택·해설에 집중한다. 직접 학습 경로도 항상 제공한다.

## 공간과 콘텐츠

중앙 놀이공원과 여섯 주변 섬, 열두 연결 다리를 유지한다. 여섯 학습 기능은 이 세계 안의 전시물과 직접 학습 목록에 연결하며 지도 형상을 대체하지 않는다. 전시물 열 곳은 섬 주제에 맞는 콘텐츠를 보여 준다. 논리 장치의 문과 울림 극장의 현은 실제 조작 가능한 대상이다.
