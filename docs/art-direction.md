- 화면 관찰: 기존 수관 두 종류가 서로 다른 조형을 사용. 다리 난간/광원/책/화단이 동일한 시각적 강도로 분산. 주요 랜드마크 뒤로 또 다른 건물이 겹침. 캐릭터는 작은 거리에서 점묘 표면으로 보임.

- 실행 확인 대상: 새로운 열린 성문/짧은 다리/건물 뒤편의 키보드 및 클릭 경로, 카메라 가림, 모바일 문제→해설→응용 흐름, 새로고침 후 재개, 저장 실패, 저모션, 렌더러 성능. 결과는 qa-report.md에 실제 확인 범위만 기록.
