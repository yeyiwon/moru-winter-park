# 지식 연구소 구현

정적 HTML / ES modules / Three.js 0.170. 외부 폰트·분석 SDK 없이 코드 기반 3D 자산을 사용한다. 이번 수정은 기존 놀이공원과 일곱 섬의 지형·주요 건축물을 유지하며 학습 구조를 연결했다.

## 실행과 확인

- 로컬: `python3 -m http.server 4188 --directory dist`
- 자동 검사: Node 22에서 `npm install` 후 `npm test`.
- jsdom 검사는 DOM 모델이다. GPU 렌더링·브라우저 레이아웃·실제 터치 검사가 아니다.
- 자산 렌더: `node scripts/export-assets.mjs`, Mitsuba 3.9.1/Pillow/numpy 환경에서 `python scripts/render-meshes.py front` 및 side/back/bright/walk/land/world/garden/castle-back. 실제 앱 메시를 사용하지만 조명과 PBR 셰이딩을 근사한다. WebGL 하늘·수면 셰이더·스프라이트·UI는 재현하지 않는다.

## 구성

- `world-layout.js`: 일곱 섬, 열두 다리, 여섯 학습 기능, 열 곳의 전시물, 플랫폼 높이.
- `themepark-world.js`: 성·관람차·회전목마와 중앙 공원. 정적 메시를 섬·재질별로 묶어 렌더 대상 수를 줄인다.
- `world-art.js`: 주변 여섯 섬의 고유 건축물, 공통 식생·다리·산책로.
- `movement.js`, `navigation.js`: 키보드·터치·클릭 공통 이동과 A*. 실제 벽/탑에 맞춘 성 충돌, 온실 입구와 수반 경계.
- `companion.js`: 연속 벨벳 곡면, 콩눈, 거리 기반 걸음, 회전·착지·체형 변화 중 지지 발 보정.
- `park.js`: 렌더링, 카메라 가림 감지, 근접 질문, 물결 이동 표시, 설정 미리보기.
- `content/*.json`: 68개 본문과 각 본문의 즉시 응용·별도 복습, 출처와 검토 상태.
- `learning-core.js`: 저장·복습 기록·요청 병합·콘텐츠 캐시·실패 처리.
- `simulations.js`, `effects.js`: 계절·동전·몬티홀·조건 다리·그래프 축·합성 음색 모형과 효과음.
- `app.js`: 예상→근거 기록→추가 증거→판단→핵심/상세 해설→응용, 직접 학습과 복습.
- `studio.js`: 일곱 섬 지도, 조명·캐릭터·소리 설정. 캐릭터 정면/측면/후면과 밝은 배경 확인.
- `sw.js`: 같은 출처의 명시된 정적 파일만 캐시. API·인증 응답은 대상이 아니다.

## 콘텐츠와 API 경계

본문 68개, 대표 12개, 응용 68개와 지연 복습 68개를 구분한다. 13개 분야, 9개 유형, 6개 조작 모형이다. UI 본문 수에 응용·복습을 중복 합산하지 않는다.

`source-checked`는 AI 보조 출처 대조이며 독립 전문가 심사가 아니다. 법 문항은 제시된 조문·조건의 개념 이해만 판정한다. 구체 사건의 적법 여부나 가치 판단 자체를 채점하지 않는다. 출처별 접근 제한은 source-review 문서에 남겼다.

실시간 AI API는 연결하지 않았다. 자유 서술은 근거 기록이며 자동 채점하지 않는다. API 응답이나 서버별 사용량 제한을 구현한 것처럼 표시하지 않는다. 자세한 연결 조건은 `api-decision.md` 참조.

학습·설정은 현재 브라우저 로컬 저장이다. 서버 동기화는 없다. 이전 `bits-v1` 기록을 삭제하지 않으며 새 문항과 자동 병합하지 않는다. 복습 변형은 원리당 1개로, 반복하면 같은 변형이 다시 나온다.
