# 지식 연구소 구현

정적 HTML / ES modules / Three.js 0.170. 외부 번들·폰트·분석 SDK 호출 없음. 직접 제작한 코드 기반 3D 자산.

## 실행

- 로컬: `python3 -m http.server 4188 --directory dist`
- 검증: `npm install` 후 `npm test` (Node 22 이상).
- jsdom은 개발 검사 전용. 사이트에 포함되지 않음.

## 구조

- `world-layout.js`: 두 테라스, 여섯 장소, 건물 충돌 범위.
- `movement.js`, `navigation.js`: 공통 키보드·터치·클릭 이동과 A* 경로.
- `world-art.js`: 공통 재질과 건축·식생·통로. 정적 메시를 재질별로 합쳐 오브젝트 수 제한.
- `companion.js`: 개별 털 없는 벨벳 캐릭터와 거리 기반 걸음·눈꺼풀·접지.
- `park.js`: 렌더링·상호작용·카메라 가림 감지·접근 질문·장치 상태.
- `content/*.json`: 60개 본문, 각각의 즉시 응용 및 별도 복습, 출처/검토 상태.
- `learning-core.js`: 저장, 기록, 복습 시점, 요청 병합·캐시·실패 처리.
- `simulations.js`: 독립 시행, 몬티홀, 진리표, 그래프 축, 계절 단순 모형.
- `app.js`: 예측→추가 증거→판정→핵심·상세 해설→응용 흐름, 직접 학습, 복습.
- `sw.js`: 같은 출처 파일 캐시. 처음 실행할 때의 네트워크는 필요.

## 콘텐츠 운영 경계

source-checked는 AI 보조 출처 대조이며 독립적인 인간 전문가 검수가 아니다. 60개 본문과 60개 즉시 응용, 60개 별도 복습은 구분한다. UI의 콘텐츠 수는 본문 60개이며 응용을 별도 본문처럼 부풀리지 않는다. 자유 서술은 자동 평가하지 않는다. 복습 변형은 원리당 현재 1개이므로 재차 복습하면 같은 복습 상황을 다시 보게 된다.

## 알려진 범위

- 실제 사용자 기기에서 성능을 자동 수집·전송하지 않는다. 설정의 10초 측정은 현재 화면에만 결과를 보여 준다.
- 정적 장면 생성 비용은 Node에서 별도 측정할 수 있지만 FPS가 아니다.
- 데스크톱/모바일 실제 WebGL, 밝은/어두운 배경의 캐릭터 외형, 카메라 가림 해소 품질은 브라우저에서 확인해야 한다. 연결이 없던 이번 수정 후에는 이를 검증했다고 표시하지 않는다.
- 설정·학습 기록은 현재 브라우저 저장소만 사용. 서버 동기화 없음. 기존 간단 퀴즈 저장 키(bits-v1)는 삭제하지 않지만 새 문항 ID와 자동 합치지 않는다.
