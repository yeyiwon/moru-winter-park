# Visual Revision 01 — 료칸 족욕장 (실험 브랜치)

2026-11-24 · 브랜치 `experiment/visual-revision-ryokan` · 기준 `main` `c2fbc3f` · **운영 미반영, 병합 전 검수 필요**

추가 비용 0원. 새 도구·자산·의존성 없이 기존 Three.js 코드만 수정했다. 멀티플레이, 이동, 좌석, 충돌, 오디오 코드는 건드리지 않았다.

## 무엇이 문제였나 (수정 전 화면에서 확인)

1. 실내에 그림자가 하나도 없었다. 그림자를 만드는 유일한 광원(달빛)이 실내에서는 세기 0.12로 내려가고 천장에 막혀 바닥에 닿지 않았다. 화분·난간·캐릭터가 떠 보였다.
2. 마루가 거의 검게 뭉개졌다. 실내 광량이 반구광 0.58과 점광원 몇 개뿐이라 반사율이 낮은 바닥이 묻혔다.
3. 족욕장이 "바닥에 놓인 상자"로 읽혔다. 테두리는 긴 판 4개였고 옆면에 달걀 모양 돌이 박혀 있었다.
4. 물이 불투명한 청록 판에 흐릿한 흰 얼룩이었고, 실내인데 야외 하늘을 반사했다.
5. 창밖 풍경이 창에 붙은 평면 그림이라 카메라를 움직여도 시차가 없었고, 나무에 가로 줄무늬가 보였다.

환경: 헤드리스 Chrome + 소프트웨어 렌더러(llvmpipe), 1440×900, 품질 medium, 같은 카메라·같은 아바타·같은 좌석. 캡처 도구는 `verify-ryokan-v57.mjs`의 QA 훅과 카메라 좌표를 그대로 썼다.

## 실패한 접근

- **캐릭터 털을 굵게 눕히기:** 섬유 굵기 1.25mm→4.4mm, 길이 단축, 아래로 빗질. 가까이서 고슴도치·성게처럼 보여 수정 전보다 나빠졌다. 원복했다. 섬유 26,000가닥으로는 굵기를 올려도 면이 채워지지 않는다. 털은 이번 변경에 포함되지 않는다.
- **강돌을 테두리 전체에 두 줄로 두르기:** 삼각형 +17,000으로 료칸 예산 테스트 실패. 모서리와 긴 변 일부에만 25개를 두는 것으로 바꿨다.
- **물 바닥 돌을 선명한 보로노이 경계로 그리기:** 물이 아니라 무늬 타일로 읽혔다. 경계를 부드럽게 하고 물색 흡수를 올렸다.
- **상부광을 거의 수직(약 14°)으로 두기:** 그림자가 물체 바로 밑에 숨어 보이지 않았다. 33°로 기울였다.
- 캡처: 좌석 배정이 실행마다 달라 전후 구도가 어긋났다. 기준 좌석을 잡을 때까지 재시도하도록 고쳤다.

## 알려진 한계

- 천장 등롱의 뚜껑이 바닥에 작은 어두운 얼룩 그림자를 만든다. 등롱이 다른 목재와 한 메시로 합쳐져 있어 따로 뺄 수 없었다.
- 상부 키라이트는 벽을 통과하는 가짜 광원이다. 창에서 들어오는 빛의 방향성은 표현하지 않는다(창 아래 빛 웅덩이는 데칼).
- 물은 장면을 실제로 반사·굴절하지 않는다. 방의 반사는 해석적 근사이고, 물에 잠긴 발은 보이지 않는다.
- 창밖 나무는 양식화된 실루엣이다. 가까이서 보면 층층이 쌓은 형태가 드러난다.
- 방의 구조(높은 천장, 넓은 빈 마루, 상자형 가구)는 그대로다.
- 다른 실내(박물관, 천문대)와 야외는 변경하지 않았다.

## 독립 검수

**미완료.** 구현과 분리된 검수 에이전트에게 같은 구도의 전후 7쌍을 전달해 "기술 작동 여부"와 "미술적 완성도"를 따로 평가하도록 요청했으나, 이 문서를 닫는 시점에 결과를 받지 못했다. 검수 결과가 나오기 전에는 병합하지 않는다.

구현자 자체 평가(검수를 대신하지 않음): 접지 그림자, 마루 가독성, 창밖 풍경은 수정 전보다 나아졌다. 물은 깊이감이 생겼지만 바닥 돌 무늬가 아직 도드라진다. 털은 그대로다. 장면 전체가 "완성된 스타일라이즈드 3D" 수준이라고 보지는 않는다.
