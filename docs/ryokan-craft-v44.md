# 료칸 내부 마감과 넓어진 시야 — v44

## 문제와 적용 범위

높아진 실내 카메라에 기존 6.7m 보와 7.25m 천장이 맞지 않았고, 넓은 목재 방 안에서 족욕·식사·휴식 구역을 구분하는 건축 마감이 부족했다. 가구를 통로에 추가하지 않고 기존 fixture 안의 마감, 벽면, 천장 구조로 구역의 성격을 보강했다.

외부 섬, 건물 출입문, 실내 가구의 충돌 경계, 좌석 위치와 좌면 높이는 그대로 사용한다. 카메라 작업에서 조정한 중앙 홀 입장 지점과 `interiorRooms.ryokan.ceiling`은 공통 layout을 따른다.

## 실제 변경

- `interior-world.js`의 벽과 지붕은 `interiorRooms.ryokan.ceiling`에서 높이를 계산한다. 현재 11.5m 천장에 맞춰 전체 높이의 불투명 backing, 사람 높이의 장지, 상부 회벽과 목재 수직재를 구성했다. 별도 외부 월드를 실내에서 렌더링하지 않는다.
- 지붕·보·격자 천장의 가장 낮은 부분은 천장보다 0.27m 아래에 있다. 카메라 상한인 천장 아래 0.45m보다 위에 있어 낮은 보가 카메라에 끼어드는 문제를 줄인다.
- 중복 생성되던 세로 보를 한 번씩만 만들고, 중앙 홀의 큰 펜던트 2개는 없앴다. 네 구역의 목재 격자와 얇은 emissive 간접광으로 천장에 규칙을 주었다. 새 동적 광원은 추가하지 않았다.
- 오마카세는 둥근 모서리의 목재 상판, 세로 목재 마감, 주방 뒤 장지/선반, 빈 도기와 접힌 천으로 정리했다. 모든 추가 요소는 기존 counter 또는 chef-preparation fixture 안에 있다.
- 손님 자리에는 접힌 천, 젓가락과 받침만 둔다. 음식은 기존 서버 시각 기반 셰프 전달 로직이 맡는다. 비어 있는 카운터에서 계속 나오던 정적인 김 효과도 제거했다. `ryokan-chef.js`와 서빙 타임라인은 이 작업에서 변경하지 않았다.
- 기존 차 벤치에는 얇은 쿠션과 등받이를 더했다. 쿠션 윗면은 기존 `seatY = 0.6775`와 맞춘다. 창가 풍경 2곳은 얕고 닫힌 셰이더 배경이며 실제 외부로 뚫린 창이 아니다.
- 족욕 가장자리는 무작위 바위 더미 대신 연속된 석재 테두리와 작은 줄눈으로 변경했다. 기존 좌면 높이 0.49m를 유지하고, 석재와 모서리 돌은 기존 5.8 × 4m 경계 안에 둔다. 물은 기존 `createOnsenWater` 셰이더와 시간 갱신을 유지한다.
- 수족관의 하부 석재 마감과 얇은 차가운 빛, 양옆 목재 마감을 추가했다. 수족관 유리, 물, 물고기 LOD와 애니메이션은 그대로 유지한다.

## 모델 비용 측정

동일한 `buildInteriors(scene, { lazy: true }).ensure('ryokan')` 객체 트리를 순회했다. 화면에 가려진 오브젝트도 포함한다. 삼각형은 각 mesh의 저장된 index/position 수를 세며, InstancedMesh는 원형 geometry를 한 번만 센다. **아래 값은 실제 GPU draw call이나 프레임 시간 측정치가 아니다.**

| 항목 | 변경 전 | 변경 후 | 차이 |
| --- | ---: | ---: | ---: |
| Mesh 객체 | 88 | 96 | +8 |
| 저장된 삼각형 | 92,153 | 96,149 | +3,996 / 약 4.3% |
| 저장된 정점 | 109,278 | 115,106 | +5,828 |
| Points 객체 | 3 | 3 | 동일 |
| 광원 객체 | 3 | 3 | 동일 |
| Material 객체 | 43 | 45 | 창가 셰이더 2개 |

새 목재/석재/천 디테일은 기존 팔레트를 공유하고 마지막 `mergeFinish(root)`에서 기존 재질별 배치에 합쳐진다. 목재 슬랫 하나마다 별도 런타임 mesh를 유지하지 않는다. 새 렌더러, 텍스처 다운로드, 네트워크 갱신, 상시 애니메이션 루프는 없다. 기존 lazy loading 및 비활성 실내 해제 경로를 사용한다.

## 검증

- 기존 입구→각 활동 지점 보행 경로, fixture 충돌, 세 좌석의 서버 예약/서빙 순서, 수족관 경계·LOD·재개, 물/증기 정지, 실내 lazy 해제 테스트 통과.
- 새 `tests/ryokan-craft.test.mjs`: 둥근 상판의 실제 치수와 윗면, 추가 디테일의 모든 정점이 기존 fixture 안에 있는지, 새 광원이 없는지 확인.
- 높아진 카메라 위치에서 네 벽과 지붕에 실제 raycast가 닿으며 불투명 경계가 남는지 확인.
- 기존 좌석 raycast로 아바타 바로 아래에 원래 높이의 물리적 좌면이 있는지 확인.
- 초기 료칸에서 `chef-serving.visible === false` 확인. 기존 식사 테스트가 준비→전달→식사 순서, 취소·종료 시 접시 정리를 별도로 검사한다.

2026-11-18 최종 포커스 회귀는 아래 명령으로 **42개 통과, 실패 0개**였다.

```sh
node --experimental-vm-modules --test tests/ryokan-craft.test.mjs tests/interiors.test.mjs tests/districts-v32.test.mjs tests/ryokan-v33.test.mjs tests/ryokan-service.test.mjs tests/retreat-atmosphere.test.mjs tests/performance-architecture.test.mjs
```

실제 기기 FPS, GPU 시간, 모바일 발열은 이 모델 검증에서 측정하지 않았다. Blender 형상 검사는 브라우저의 procedural water, emissive 처리, 후처리와 동일하지 않으므로 런타임 화질 증거로 사용하지 않는다.

## 파일

- `dist/interior-world.js`: 실내 shell, 가구 마감, 물 테두리, 높이 파생 및 기존 시스템 연결.
- `dist/ryokan-craft.js`: 둥근 상판과 기존 fixture 안의 정적 마감. 방의 최종 배치·해제 경로를 공유한다.
- `tests/ryokan-craft.test.mjs`: 새 마감의 경계/높이/실내 폐쇄성 회귀.
