# v61 — 불꽃 피날레와 안내 여백

## 변경 이유와 범위

마지막 텍스트가 아닌 가장 큰 불꽃으로 마무리하라는 요청을 반영했다. 음악별 coda 전 약 12초를 전용 피날레로 구성해 기존 랜덤 절과 중복하지 않는다. 6발 부채꼴 연속 발사 → 3발 겹불꽃과 지상 분수 → 높은 다색 국화 5발·금빛 버드나무 2발·낮은 은빛 반짝임 4발로 이어진다. 마지막에는 새로 발사하지 않고 남은 불꽃만 내려오며 사라진다. 글씨·하트·추가 회전은 사용하지 않는다.

`dist/firework-score.js`만 공연 구성을 변경했다. 서버가 정한 음악·시작 시각·seed로 결정되며 음악 길이, 동시 공연 승인, 쿨다운, 개인 BGM 복원, 오디오 재생 코드는 유지했다. `dist/ryokan-meal.js`는 문장 앞 반복되는 `셰프 · `만 제거했다. `dist/resort-ui-v43.css`는 입력 자체의 시작 여백을 8px 추가하며 패널 크기·색은 유지한다.

## 검증

- 공연·타임라인·음악·게임플레이 관련 43/43 통과. 기존 글씨 기대값은 새 피날레 계약으로 교체했다.
- 3곡 × 32 seed에서 전체 타임라인을 검사해 기존 24 shell 동시 용량을 넘지 않음. 최대 Love 18, Wedding Entrance 18, Trepak 17.
- high/medium/low에서 피날레 층을 누락 없이 패킹하고 같은 배열을 재사용하며 종료 시 drawRange=0.
- 실제 Mac Chrome PC 및 390×844 터치 에뮬레이션 11/11 통과. 입력 여백 8px 및 총 시작 여백 20px 이상, 가로 넘침 없음, 셰프 문구 7단계 접두어 없음, WebGL/브라우저 예외 없음.
- PC 3곡과 모바일 low의 상승·폭발·낙하 화면을 직접 확인했다. [검사와 프레임 측정](../qa/finale-v61/report.json).
- 기존 v60 공식 주소에서 WebSocket 연결, 채팅 중 자신의 걷기/월드 지속, 채팅 종료 후 경로 유지, 예외 없음 4/4 확인. [v60 운영 검사](../qa/chat-world-v60/production/browser.json).

## 성능과 한계

입자 버퍼 51,840개와 한 개 Points 렌더 경로 유지. low는 shell당 96개, high는 360개 방향 입자를 사용한다. 반복 공연 뒤 도형·텍스처 증가 없음.

5초 피날레 샘플: PC high Love 60.2 FPS, Wedding Entrance 55.2 FPS, Trepak 40.0 FPS. 터치 에뮬레이션 low Trepak 55.8 FPS. 서로 다른 시점의 로컬 브라우저 측정이며 전 기기 60 FPS나 무지연 보장이 아니다. 물리 Windows/Galaxy/iPhone 및 장시간 발열은 UNKNOWN.

운영 배포 결과는 [DEPLOYMENT](DEPLOYMENT.md)에 기록한다. 운영 데이터 삭제·DB 변경·실시간 서버 교체 없음.
