# 개발 기록

## 2026-11-18 — v36 UI 복구와 구역 배치

v35의 청록 공통 토큰이 투과감을 잃게 만든 원인을 확인했다. 설정 제목과 하위 탭을 분리하고 료칸 전체 좌표 변환, 다리·입장·수면·지도 동기화를 적용했다. 관람차 정면 접근, 앞쪽 별빛 만물관, 팝콘·이동 중 비눗방울도 함께 반영했다. 전체 338개 및 최종 관련 10개 검사, 실제 PC·모바일 보행과 온천, 30개 설정 화면 검사를 통과했다. 동일 medium 품질의 두 구역에서 수정 전후 약 60fps를 확인했다. 실물 모바일은 미검증이다. [배치·검증·한계](layout-v36.md)에 기록한다.

릴리스 `a2e1bf7`: GitHub main, Sites 버전 36, Vercel 운영 배포 완료. 두 주소의 앱 파일과 서버 연결 확인. Vercel은 기존 Git 연결의 자동 배포를 사용했다. [배포 증거](../qa/browser-v36/production.json).

## 2026-11-18 — v35 UI 및 선택적 AI (운영 배포 전)

공통 UI 토큰, 명시적 선호 기반 음악 추천, 검토된 콘텐츠만 사용하는 전시 카드, 선택적 음성 명령을 구현했다. 실제 브라우저 실행은 자동 승인 검토의 사용량 한도로 실행되지 않았다. 로컬 자동 검사와 빌드 결과, 미검증 항목을 [v35 기록](ui-ai-v35.md)에 구분했다. 기존 온천·다섯 섬·익명 게스트·멀티플레이를 유지하며 운영 사이트는 아직 v34다.
