# 개발 기록

## 2026-11-18 — v37 최종 시각·풍선 피드백

풍선은 종류/색을 모두 무작위로 받는 단일 행동으로 정리했다. 길어진 끈·월드 관성으로 이동과 방향 전환에 부드럽게 반응한다. 부스 48개 풍선과 상시 비눗방울, 투명 장식 풍선을 추가했다. 스키 펜스의 원거리 조명을 강화하고 이정표를 다리에서 약 11m 더 들어간 베이스에 정렬하고 앞의 안내 팝업과 옆 가로등은 제거했다. 초급 하차장 끝의 3.8m 절삭은 접근 전에 완만하게 사라지도록 수정했다. 지도 아이콘은 고유 색상만 남기고 테두리/배경을 제거했으며 정상 툴팁은 아래쪽으로 표시한다. 지도는 양쪽 리프트 베이스/하차장으로 바로 이동하며 높이 좌표까지 반영한다. 트리 조명은 돌바닥 중앙에 매입하고 최종 피드백으로 6개/48% 광량으로 절제했다. 빛 방향은 고정하고 내부 결만 천천히 흐른다. 천문대는 최종 정정에 따라 돌바닥을 유지하고 추가한 상향 조명만 제거했다. 트리 주변 벤치에서는 중복 트리 꾸미기를 빼고 앉기를 유일한 기본 행동으로 바꿨다. [풍선 상세](balloons-v37.md), [광장·스키 상세](resort-festival-v37.md).

## 2026-11-18 — v37 후속 요청: 스키 리조트·축제 광장·불꽃놀이

스키장 내부를 네 코스와 좌우 두 리프트로 교체했다. 경로 길이 기반 이동, 완만한 서버 시계 보정, 프레임당 단일 좌석 좌표 계산으로 리프트 속도·동기화 불연속을 수정했다. 오뎅·모닥불을 하단 휴식 공간에 보존했고 우체국 옆 `tree-bench-5`만 제거했다. 천문대 현관·돔·아치를 개선하고, 트리 광장은 놀이공원과 같은 돌바닥 및 밑동에서 올라오는 빛으로 맞췄다. 탑승 시 지지탑 충돌 때문에 카메라가 13.8m 튀던 원인은 선택적 구조물 투명화로 수정했다. 온천 위 리본은 제거하고 설정 각 탭의 한·영 제목을 통일했다. [배치·원인·최신 검증](resort-festival-v37.md).

참조 이미지 기반 SVG 로딩, 손에 들고 걷는 스파클러, 관리자 실행·서버 동기화 3D 불꽃놀이를 구현했다. Vercel 프록시의 실내/운영/공연 경로 누락도 수정했다. [구현·검증·운영 방식](luminous-fireworks-v37.md).

## 2026-11-18 — v37 유리 UI·리조트 건축·공유 좌석

유리 표면과 충돌하던 필드/드롭다운 토큰을 통일하고, 닉네임을 서버와 입력창 모두 보이는 글자 10자로 제한했다. 멍한 눈·클레이 하트/별·고양이 귀·털을 수정하고 불투명 고글에서 눈이 돌출되는 문제를 해결했다.

별빛 만물관은 돔·기둥·몰딩·천체 장식을, 료칸은 처마·목재 짜임·등롱과 실내 천장을 보강했다. 기존 출입구와 다섯 섬 구조를 유지했다. 22개 위치의 2인 좌석, 앉는 다다미, 실제 준비 상태에 맞춘 실내 로딩, 단일 GPU draw 불꽃놀이와 조명·오로라를 적용했다. 스키 코스를 좌우 분기/하부 합류로 정리하고 리프트 하부와 공통 충돌·지도 데이터를 함께 갱신했다.

자동 검사에서 발견한 벤치의 보행로 침범은 위치를 개별 조정해 해결했다. 최종 피드백에 따라 트리 벤치에서는 앉기만 표시하며 주변 트리 꾸미기는 벤치를 벗어난 뒤 표시한다. 실제 PC/모바일 화면·공유 좌석·네 코스 활강 검사와 성능 비교는 [v37 상세 기록](winter-v37.md)에 정리한다. 실물 모바일은 미검증이다.
