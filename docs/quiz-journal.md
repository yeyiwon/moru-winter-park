# 별빛 만물관 · 개인 지식집

## 변경 이유

기존 `quick-quiz.js`는 열린 퀴즈 세션의 정답 수만 관리했습니다. 창을 다시 열면 진행이 초기화됐고, 천문대에서 풀어본 질문·해설을 개인별로 다시 찾는 기능이 없었습니다. 기존 학습실의 `learning-core.js` 기록은 다른 콘텐츠용이므로 천문대 기록을 덮어쓰거나 합치지 않았습니다.

## 이용 흐름

- 천문대 퀴즈는 혼자 바로 풀 수 있는 중앙 패널입니다. 문제, 내 선택, 정답, 해설과 출처가 같은 화면에서 이어집니다.
- 퀴즈의 `내 지식집` 또는 설정의 같은 이름 버튼에서 개인 기록을 엽니다.
- `푼 문제`, `맞힌 문제`, `담은 지식`으로 기록을 구분합니다. 틀린 질문도 해설을 다시 읽고 담을 수 있습니다.
- 기록의 `다시 풀기`는 현재 제공 중인 문제로 돌아갑니다. 문제 내용이 수정되면 과거 해설은 기존 기록에 남습니다.
- 퀴즈와 지식집을 전환할 때 다른 패널을 닫고 입력 소유권을 전환합니다. 월드 연결은 유지합니다.

## 저장·권한

`/api/quiz-journal`은 기존 인증된 익명 방문자 세션을 사용합니다. 별도 계정이나 개인정보 입력은 추가하지 않습니다. 호출자는 다른 방문자의 ID를 지정할 수 없습니다.

- `GET`: 자기 기록만 50개씩 읽습니다. `nextCursor`로 다음 기록을 요청합니다.
- `POST action=answer`: 문제 ID, 표시된 콘텐츠 리비전, 선택한 보기, 요청 식별자를 전송합니다. 서버의 현재 검증된 문제은행과 관리자 검토본으로 채점합니다. 클라이언트가 정답이나 해설을 전송해 기록을 위조하는 형태는 허용하지 않습니다.
- `POST action=save`: 이미 풀어본 자기 기록의 담기 상태를 변경합니다.
- 문제 리비전은 콘텐츠 동일성 식별자이며 인증 토큰이 아닙니다. 수정되거나 출제 중지된 문제의 오래된 답변 요청은 저장하지 않습니다.
- 같은 문제 리비전은 카드 한 개로 유지하고, 바로 이전 답변 요청의 재전송은 시간·결과를 다시 변경하지 않습니다. 현재 답변 결과와 이전에 맞힌 적이 있는지를 별도로 보관합니다.

새 `quiz_journal` 테이블에 문제·보기·정답·해설·출처 스냅샷을 저장합니다. 마이그레이션 `0015_quiz_journal.sql`은 새 테이블과 인덱스만 추가하며 기존 익명 방문자·소원·장식 데이터를 변경하지 않습니다. Drizzle schema, snapshot, journal을 함께 생성했습니다.

## 연결 실패와 재방문

브라우저 캐시는 게스트 ID별로 분리하며 최근 200개 카드를 보관합니다. 서버 기록은 페이지를 넘겨 더 볼 수 있습니다. 서버 저장에 실패하면 서버에 저장됐다고 표시하지 않고 브라우저 보관 상태를 보여줍니다. 브라우저 저장도 사용할 수 없으면 현재 화면에서만 보이는 기록임을 알립니다.

게스트 연결이 바뀔 때 기록을 다시 읽고, 이전 연결의 비동기 응답이 새 게스트의 캐시에 들어가지 않도록 확인합니다. 게스트 ID와 함께 세션 세대를 확인하므로 같은 게스트 ID로 연결이 끝났다 복구된 경우도 구분합니다. 브라우저 시계가 서버보다 앞서더라도 같은 답변의 서버 확인 결과가 로컬 대기 상태에 가려지지 않게 처리합니다.

오프라인 답변을 담을 때에는 답변 재전송 후 담기 요청이 이어집니다. 독립 검토에서 첫 응답 대기 중 게스트가 바뀌면 후속 담기 요청이 새 게스트로 전송되는 문제를 재현했습니다. 각 응답 이후 세션을 다시 확인하도록 수정했습니다. 이전 세션에서 이미 보낸 답변이 완료될 수는 있지만, 새 세션에 후속 쓰기를 보내거나 저장 완료로 합치지 않습니다.

계정 복구를 추가한 것은 아닙니다. 익명 세션이나 브라우저 데이터가 삭제되거나 다른 기기로 이동하면 이전 기록에 자동 연결된다고 보장하지 않습니다. 오프라인 기록의 무조건적인 백그라운드 재전송도 하지 않습니다. 사용자가 기록을 담을 때 다시 서버 저장을 시도할 수 있습니다.

## UI·성능

`quiz-journal.css`는 한 개의 중앙 질문 카드와 지식집 화면에만 적용됩니다. 창의 헤더·스크롤 본문·하단 조작을 분리하고 작은 화면과 낮은 화면 높이에 대응합니다. 짧은 정답 효과는 움직임 감소 설정을 따르며 모바일에서는 표시 입자 수를 줄입니다. 추가 3D 렌더러는 만들지 않습니다.

지식집 요청은 패널 열기·답변·담기 동작에서만 발생합니다. 매 프레임 동기화하지 않습니다. 다른 사용자의 카메라나 퀴즈 진행에는 영향을 주지 않습니다.

## 변경 파일과 통합 지점

- `dist/quick-quiz.js`: 중앙 카드, 선택 표시, 기록·담기, 지식집 전환.
- `dist/quiz-journal.js`: 개인 기록 UI, 브라우저 캐시, 서버 저장 상태.
- `dist/quiz-journal-data.js`: 콘텐츠 스냅샷·리비전·기록 병합.
- `dist/quiz-journal.css`: 중앙 카드와 반응형 지식집 스타일.
- `server/quiz-journal.js`: 세션별 조회·서버 채점·담기 API.
- `db/schema.js`, `drizzle/0015_quiz_journal.sql`, 관련 `drizzle/meta`.
- 통합 지점: `server/api.js`의 세션 검증 이후 라우팅, `index.html`의 CSS와 메뉴 접근, `panels.js`의 공통 입력 상태, 서비스 워커의 새 자산.
- Vercel 통합: `server/vercel-proxy.js`의 허용 경로에 `quiz-journal`을 추가했습니다. 조회는 페이지 위치 `cursor`만 전달하며 클라이언트가 지정한 소유자 쿼리는 전달하지 않습니다. 기록의 소유권은 실제 백엔드 세션이 결정합니다.

## 검증

실행 명령:

```sh
node --experimental-vm-modules --test tests/quiz-journal.test.mjs tests/quick-quiz.test.mjs tests/social-ui.test.mjs tests/ryokan-service.test.mjs
```

관련 통합·회귀 테스트 22개 통과. 지식집의 5개 테스트와 퀴즈·게스트 연결·오마카세 회귀를 함께 실행했습니다. 새 API 검증은 별도 임시 SQLite에서 수행했습니다. 앞선 `trivia-loader.test.mjs`, `shared-rides.test.mjs` 회귀도 통과했습니다. Vercel 프록시의 `tests/vercel-proxy.test.mjs` 7개 검증도 통과했습니다.

확인한 동작:

- 서로 다른 게스트의 기록 조회·담기 권한 분리.
- 서버 채점, 요청 재전송, 기존 카드 갱신, 정답 이력 유지.
- 문제 수정 후 과거 스냅샷 보존, 오래된 리비전·출제 중지 거부.
- 혼자 풀기 → 저장 → 지식집 → 담은 지식 → 다시 풀기.
- 패널 전환 후 입력 차단 유지, 게스트 변경 시 기록 분리.
- 서버 연결 실패를 브라우저 보관 상태로 표시.
- 실제 `handleAPI` 라우팅을 통한 입장·기록·담기, 미입장·만료 초대·다른 출처의 변경 요청 거부.
- 지연시킨 답변 응답 중 다른 게스트로 전환했을 때 후속 담기 요청이 나가지 않고 다른 게스트의 저장 상태가 유지되는지 확인.
- 같은 게스트 ID로 세션 종료·복구 후 도착한 응답과 이전 화면의 담기 콜백이 새 세션에 반영되지 않는지 확인.

테스트는 Node·JSDOM과 임시 SQLite 검증입니다. 실제 브라우저의 배치와 실물 모바일 성능은 별도 통합 검증 대상이며 이 문서 작성 시점에서는 UNKNOWN입니다. 실제 측정 FPS 개선치를 주장하지 않습니다.
