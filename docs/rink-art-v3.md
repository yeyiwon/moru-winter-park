# 아이스링크 자산 v3

`winter-retreat.js`는 `retreat-layout.js`의 링크 크기·입구·부스·가로등·벤치 위치를 그대로 사용합니다. 우체통은 우체국 기준 `x+w/2+.8, z+1.15`에, 부스 랜턴은 `x±w*.41, z+d/2+.5`에 있습니다.

확장 링크의 경계에는 낮은 실버 난간, 아치 장식, 샴페인색 조명 줄과 높은 피니얼이 이어집니다. 동쪽 입구는 비워 두고 두 출입 기둥(radius .23)은 경계 양끝에 둡니다. 둘레 보행대는 높이 .105m로 지형과 같은 레벨에 맞춥니다. 4개 목재 벤치와 확장된 타원 공간이 휴식/스케이팅 영역을 나눕니다.

얼음은 물리 재질의 투명 상층, 아래쪽 색층, 정빙선·미세 기포·가장자리 서리·가로등 방향 하이라이트를 그리는 얇은 shader층으로 구성합니다. 가로등 하이라이트는 수식으로 만든 표현이며 다른 건물/캐릭터를 실시간으로 비추는 평면 반사가 아닙니다. `time`은 움직임 줄이기 설정에서 정지합니다.

전용 자산은 16 mesh / 101,074 triangles로, 불투명 장식은 마감별로 병합합니다. 실제 점광원은 링크 2개와 우체국 1개이고 조명 줄은 발광 재질을 공유합니다. 게이트의 실제 메시를 향한 9개 신체 높이/폭 ray 검사는 통과했습니다. 전체 월드의 카메라/이동/성능과 WebGL shader는 통합 브라우저 점검 대상입니다.

Blender는 이 런타임 메시의 GLB 내보내기와 오프라인 검토 렌더에 사용합니다. 오프라인 이미지와 GLB는 WebGL shader를 그대로 재현하지 않습니다. 런타임은 동일한 제작 메시를 동기 생성하며 새 모델 로더나 production dependency를 추가하지 않습니다.

검증 완료: 최종 공유 배치를 직접 import한 `tests/rink-assets.test.mjs` 3/3 통과. Blender 5.2.1에서 최종 배치를 렌더링하고 확인했으며, 중복 정점을 정리한 GLB 2.0(16 mesh / 16 material / 1,929,628 bytes)을 내보냈습니다. GLB는 검토용 별도 산출물로 저장했고 배포 번들에는 중복 포함하지 않습니다.
