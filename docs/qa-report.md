## 실제 확인한 이미지

`qa/asset-review/`의 front, side, back, bright, walk, land, world, garden, castle-back PNG.

이 이미지는 이미지 생성으로 만든 콘셉트 그림이 아니다. 앱에서 사용하는 메시·변환·색·거칠기·금속성·sheen 값을 내보내 Mitsuba 3.9.1 scalar_rgb로 렌더링했다. 외형과 비례·구조를 확인하는 **오프라인 3D 자산 검토 이미지이며 웹 화면 캡처가 아니다.** 조명과 재질 모델은 근사이고 WebGL 하늘·수면 셰이더, 스프라이트, UI는 포함하지 않는다. 미세한 렌더 샘플 노이즈를 실제 앱의 털 텍스처로 해석하지 않는다.

캐릭터의 정면·측면·후면에서 연결되지 않은 털, 가시나 줄무늬가 없고 콩눈과 둥근 실루엣을 확인했다. 걸음은 한 발을 들고, 착지에서는 두 발이 지면에 남도록 수정 후 다시 렌더했다. 중앙 공원의 성·관람차·회전목마 구도를 유지했다. 이 정지 자세 검토를 실제 보행 애니메이션의 자연스러움 검증으로 대체하지 않는다.

Blender 5.2.1은 시작 시 Metal 장치 탐색에서 충돌해 사용하지 못했다. CPU 렌더러로 전환했으며 실제 브라우저 자동화를 우회해 실행하지 않았다.

## 자동 검사

환경: macOS arm64, Node v22.4.1, jsdom 26.1.0, Three.js 0.170. DOM 검사는 실제 브라우저 레이아웃이 아니며 렌더러를 대체한 검사에는 GPU가 없다.

최종 `npm test`: **78개 통과, 실패 0개**, 10.35초. 원문: `qa/refinement-tests.txt`. 정적 문법·상대 모듈 경로·파일 참조·diff 공백 검사도 수행한다.

- 68개 본문 렌더, 선택 상태, 선택 전 제출 방지, 힌트, 증거 후 판단 수정, 핵심/상세 해설·출처·응용.
- 최초 오답→증거 후 정답→새 상황 적용의 기록, 저장과 재개, 별도 복습 정답 판정.
- 저장 접근 거부·손상, 콘텐츠 네트워크 실패·이전 캐시, 중복 요청 병합.
- 논리·확률 본문과 복습의 독립 계산·조건 검산 43개.
- 전체 섬·전시물 경로, 성문·다리 및 온실 실제 메시 통로, 수반·유리 경계.
- 실제 캐릭터 메시의 정지·체형 변경·보행 위상·착지 접지, 학습 중 장면 업데이트 정지, 커스터마이징 연결.
- 음색 모형의 공통 220Hz 기본 주파수와 440/660Hz 배음, 재생 불가 안내, 음소거 시 재생 중지.

## 성능과 남은 제한

측정 결과는 `qa/scene-metrics.json`에 기록한다. 최종 단일 실행에서 CPU 장면 구성 7141.19ms, 메시 380개, 재질 116개, 기하 삼각형 561,367개를 측정했다. `npm test` 내부 검사가 함께 실행된 환경이다. CPU 장면 구성 시간은 Node에서의 단일 측정이며 브라우저 FPS가 아니다. 메시·재질·삼각형 수는 일곱 섬 전체의 장면 데이터로, 캐릭터·접촉 그림자·물결과 GPU 추가 그림자 패스는 제외한다. InstancedMesh의 반복 수는 이 파일의 삼각형 합산에서 곱하지 않는다. 실제 화면에 그려지는 삼각형 수와도 다르다.

- 브라우저 제어 연결이 없어 **새 버전의 실제 WebGL 화면, 실제 키보드/마우스 감각, 모바일 Safari/Chrome 터치·레이아웃·FPS는 미검증**이다. 카메라 가림 해소와 투명도 정렬, 서비스 워커의 실제 오프라인 동작도 브라우저에서 확인해야 한다.
- 설정의 ‘화면 성능 확인’에는 10초 동안 현재 뷰포트·DPR·평균 FPS·프레임 p95·그리기 횟수·삼각형 수를 표시한다. 이번 환경에서는 이 기능의 실제 GPU 결과를 수집하지 않았다.
- 실시간 외부 AI API와 서버 동기화는 연결하지 않았다. 자유 서술은 기록만 하며 AI 채점이나 모의 AI 응답은 없다. 자세한 이유는 `api-decision.md`에 기록했다.
- 학습은 외부 AI 없이 동작한다. 최초 콘텐츠 다운로드에는 네트워크가 필요하다. 이후 데이터 캐시와 정적 파일 캐시를 지원하지만 실제 브라우저 오프라인 검증을 완료했다고 주장하지 않는다.

위 구현·자동 검사·자산 외형 확인과 사용자가 요청한 전체 완료 기준을 구분한다. 실기기 검증과 독립 콘텐츠 심사가 남아 있으므로 모든 완료 기준을 통과했다고 표시하지 않는다.
