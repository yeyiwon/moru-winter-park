## 성능 측정의 범위

측정 파일: `qa/scene-metrics.json`.

- Node CPU에서 장면 메시를 만드는 데 711.17ms (테스트 동시 실행 중 단일 측정).
- 정적·장치 장면 메시 52개, 재질 12개, 삼각형 165,663개. 캐릭터·접촉 그림자·이동 물결 및 GPU의 그림자 추가 패스는 이 수치에 포함되지 않는다.
- 브라우저 렌더 FPS·GPU 프레임 시간·실제 그리기 횟수는 **미측정**. 위 CPU 시간을 프레임 성능으로 해석하지 않는다.
- 앱 설정의 ‘화면 성능 확인’에 현재 뷰포트·DPR·평균 FPS·프레임 p95·그리기 횟수·삼각형 수를 표시하는 10초 측정 기능을 구현했다. 이번 환경에서는 실행 결과를 수집하지 못했다.

## 남은 검증과 기능 제한

- 작업 도중 브라우저 제어 연결이 사라졌다. 수정 전 화면은 관찰했지만 **수정 후 화면 캡처·실제 WebGL 렌더링·캐릭터 정면/측면/후면의 미적 검토는 미완료**다. 기존 화면을 새 결과의 증거로 사용하지 않는다.
- 데스크톱 실제 키보드·마우스 감각, 모바일 Safari/Chrome 터치·레이아웃·성능, 전경 가림 해소 품질, 서비스 워커의 실제 오프라인 실행은 미검증이다. 반응형 CSS와 시나리오 검사만으로 실제 기기 통과를 주장하지 않는다.
- 실시간 외부 AI API는 연결하지 않았다. 런타임에 인증 정보가 없고, 현재 정적 사이트에는 서버 중계가 없다. 모의 AI 답변도 없다. 자유 서술은 기록만 하며 자동 채점하지 않는다.
- 학습 기록은 브라우저 로컬 저장이다. 기기 간 동기화는 없다. 외부 호출 실패에도 캐시된 콘텐츠와 정적 학습 흐름이 동작하도록 구성했으나 첫 사용에는 네트워크가 필요하다.
- 새 구조의 구현과 위 자동 검사는 완료했으며, 사용자가 요구한 전문적인 시각 품질의 최종 승인은 아직 내리지 않았다.
