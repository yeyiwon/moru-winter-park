# v37 — 스키 리조트, 천문대, 트리 광장 후속 수정

## 범위

다섯 섬의 중심·연결 다리·료칸·놀이공원 위치를 유지한다. 스키장 내부의 코스·지형·리프트·휴식 시설, 천문대 외관, 트리 광장 마감과 조명만 정비했다. 식물원·아이스링크·눈썰매를 복원하지 않는다.

## 스키 데이터와 실제 지형

`resort-blueprint.js`의 공통 로컬 좌표를 `resort-layout.js`가 월드 Z +90으로 변환한다. 지형·코스·리프트·충돌·상호작용·상세 지도는 같은 데이터를 쓴다.

| 구역 | 로컬 좌표 / 역할 |
|---|---|
| 중간 하차 광장 | (-62, -296), 높이 30.09m, 초급 진입 |
| 정상 광장 | (16, -359), 높이 68.09m, 중급·상급·파노라마 진입 |
| 좌측 리프트 | (-84, -188) → (-78, -298), 26초, 2인승 |
| 우측 리프트 | (98, -202) → (60, -360), 36초, 2인승 |
| 메도우·초급 | (-42, -286)에서 하부 (-26, -174), 넓고 완만한 회전 |
| 센트럴·중급 | (-12, -346)에서 (-6, -172), S형 회전 |
| 리지·상급 | (10, -346)에서 시작, 하단 중급 합류 |
| 파노라마 하산로 | (34, -346)에서 우측을 돌아 (25, -174) |
| 휴식 공간 | 오뎅 모델 (-53, -167), 마시멜로 (-68, -164), 모닥불 (-39, -154) |

정상 테라스·중간 하차장·활강 경사·합류·감속 구간을 하나의 높이 함수로 연결했다. 리프트 하차장에서 발이 지형 아래로 들어가는 경우는 하차장 완만한 지형을 코스 높이 계산 이후 적용해 해결했다. 슬로프 위에 별도 떠 있는 평면을 얹지 않는다. 두 리프트는 활강 경로의 양옆에 있고 지지탑·케이블·의자는 실제 선로의 법선 방향으로 정렬한다.

기존 오뎅 포장마차와 마시멜로 트럭 모델, 음식 상호작용, 불꽃·불티·환경음 및 모닥불 좌석을 보존했다. 베이스를 활강 종료 / 양옆 리프트 / 휴식 공간으로 나눈다. 우측 베이스의 표지판은 ‘정상 리프트 ↗’와 ‘← 모닥불 · 어묵’을 표시한다. 새 시설이나 길을 막는 중앙 부스를 추가하지 않는다.

스키 펜스는 아이스 블루 발광과 밝은 점광 표현으로 실제 코스 경계의 2m 간격 전구와 연결 빛을 각각 하나의 Points/LineSegments로 표시한다. 먼 거리 최소 픽셀 크기를 유지해 가까이서만 켜지지 않는다. 새 PointLight는 추가하지 않았다. 우측 탑승장은 X 105→98로 당겼고, 코스 가장자리와의 최소 간격 6.09m 및 두 의자/지지대 통행을 검사했다.

다리에서 약 11m 더 들어간 스키장 진입 광장 오른쪽에 안내판 모델 (9, -156), 접근점 (9, -153)을 배치했다. 최신 요청으로 자동 안내 팝업/버튼과 안내판 바로 옆 가로등만 제거했다. 다리 접근 방향을 바라보며 눈높이에서 왼쪽 초급·푸드트럭·모닥불, 오른쪽 정상·중급·상급·파노라마를 안내한다. 작은 실제 코스 지도는 하단에 둔다. 중앙 6m 진입 폭과 겹치지 않는다.

## 리프트 카메라 원인

확인된 원인은 두 가지였다.

1. 긴 네트워크 왕복 시간의 서버 시각을 즉시 적용하고 좌석 좌표를 프레임 안에서 두 번 계산했다. `server-clock.js`는 단조 시계와 요청 중간 시각으로 보정하며, 지연 표본을 거르고 작은 오차를 점진적으로 반영한다. `winter-rides.js`는 누적 3D 경로 길이를 캐시하여 일정한 속도로 이동한다.
2. 실제 탑승 녹화에서 캐릭터는 프레임당 0.075m 이동했지만 카메라가 **13.80m** 튀었다. 카메라와 캐릭터 사이로 들어온 금속 지지탑이 일반 건물 벽처럼 처리되어 카메라 거리가 급격히 줄었다. 지지탑을 개별 그룹으로 배칭하고, 탑승 중 실제 시야를 가리는 지원 구조에만 일시적 투명도를 적용했다. 일반 보행에서는 원래 충돌을 유지한다. 공유 머티리얼을 복제하여 수정하고 종료하면 복원한다.

사용자 카메라 회전은 유지한다. 강제 회전·추가 확대·별도 시네마틱 카메라를 넣지 않는다.

## 지도

- 월드맵: `scripts/render-world-map.mjs`로 **실제 3D 월드**를 정적 WebP로 다시 렌더한다. 갱신된 설산·좌우 리프트·코스가 함께 반영된다.
- `map-atlas.js`의 투영 행렬/산 압축 변환을 마커에도 공유한다. 지도는 별도 실시간 Three.js 렌더러를 실행하지 않는다.
- 마커는 다른 4개 구역과 스키 좌측 베이스·우측 베이스·중턱 하차·정상 하차를 합쳐 8개다. 실제 높이까지 정적 지도와 같은 투영을 적용한다. 새 스키 마커는 안전한 하차 좌표로 이동하며 자동 탑승하지 않는다. 아이콘 자체에 색을 넣고 원형 배경/테두리를 제거했다. 호버는 같은 색을 유지하며 미세하게 확대한다. 위쪽 경계의 툴팁은 아래로 열어 정상 이름이 잘리지 않게 한다. 호버 이름 박스는 최종 정정대로 투명도(.24/.10/.17)와 흰 글씨를 유지하며 배경 RGB만 어둡게 조정한다. 아이콘과 이름 박스에 테두리를 추가하지 않는다.
- 코스 지도 모듈(이정표 자동 팝업은 최종 요청으로 제거): `ski-map.js`가 실제 `skiNetwork`와 두 리프트를 SVG로 그린다. 네 코스 범례를 누르면 해당 경로를 강조한다. 새로운 순간이동 목록은 없다.

재생성:

```sh
PROFILE_URL=http://127.0.0.1:4185 MAP_OUTPUT=qa/browser-v37/map-render npm run build:map
npm run build
npm run build:vercel
npm run test:budget
```

## 트리 광장과 천문대

- 우체국 옆 **tree-bench-5만 제거**했다. 다른 벤치의 예약 ID는 재번호 없이 유지한다.
- `plaza-paving.js`로 놀이공원과 트리 광장이 동일한 낮은 육각 돌바닥·색상·재질을 사용한다. 포장은 기존 설원 위에 낮게 깔며, 가장자리는 눈과 불규칙하게 이어진다. 추가 충돌체를 만들지 않는다.
- 트리 돌 포장 중앙인 반경 12.8m의 매입 조명 6곳에서 따뜻한 빛이 위로 올라간다. 최신 피드백에 맞춰 8개에서 6개로 줄이고 광량을 48%로 낮췄다. 방향은 트리에 고정하고 빛 내부의 결만 천천히 흐른다. 교차된 부드러운 팬과 GPU 잔광이 가지 방향으로 향하며, 실제 광원은 기존 제한된 광원 풀을 재사용한다. 광장 보행을 가로막는 원형 구조물은 없다.
- 천문대는 불투명 미드나이트 에나멜 돔, 곡면 프레임, 따뜻한 아치 창문, 네 기둥의 현관·박공·몰딩과 정면 별자리 포장으로 개선했다. 중앙 접근로는 평평하게 남기고 장식 계단은 양쪽에 둔다.
- 천문대는 최종 정정에 따라 기존 육각 돌 포장과 바닥 별자리 패턴을 유지한다. 최종 요청에 따라 추가한 상향 조명과 관련 파티클/광원은 제거했다. 현관·창문·돔의 기존 건축 조명은 유지한다.
- 큰 트리의 별은 보석처럼 나눈 입체 면과 얇은 외곽선을 사용한다. 별 표면 안쪽에 가려져 있던 중심 발광점은 앞/뒤 표면 바깥으로 옮겼다. 작은 트리의 별과 재질은 변경하지 않았다.
- 온천 위 리본은 제거했다. 물·수증기·폭포 효과는 유지한다.
- 설정은 공통 헤더에서 모든 탭의 영어/한국어 제목을 동일하게 표시한다. MAP/지도, CUSTOMIZE/커스터마이징, SOUND/소리, INVITE/초대, WEATHER & LIGHT/시간·날씨.

## 검증 기록

PC와 모바일 에뮬레이션 모두 좌우 2인 리프트 예약·탑승·하차, 직접 카메라 회전, 네 코스 실제 입력 활강, 장비/조작 UI 종료, 어묵·모닥불, 코스 지도와 료칸까지 실제 보행을 통과했다. 모바일 활강은 숨겨진 보조 버튼이 아닌 실제 터치 조이스틱을 사용했다. JS/셰이더 오류는 0건이었다.

지지탑을 지나는 동일 초기 구간의 최대 프레임간 카메라 이동은 PC 좌측 0.095m / 우측 0.109m, 모바일 에뮬레이션 0.073m / 0.126m다. 기존 13.80m 급이동은 재현되지 않았다. 측정 범위는 탑승 후 1.5–4.5초이며 모든 네트워크 환경에 대한 보장은 아니다.

- [모바일 터치 검사](../qa/browser-v37/resort-mobile.json)

- [PC·모바일 벤치/이정표 검사](../qa/browser-v37/context-actions.json): 앉기만 표시, F 비활성, 이정표 팝업·바로 옆 가로등 제거, 천문대 돌바닥 유지/추가 상향 조명 제거.
- 자동 검사: 코스/지형/다리/보행, 두 좌석 예약, 하차·스키 종료, 카메라 가림 복원, 인스턴스 배칭 보존.
- 실제 휴대폰과 외부 네트워크 지연이 큰 상태의 장시간 공연은 UNKNOWN이다.

## 설계 참고

[비발디 공식 소개](https://www.sonohotelsresorts.com/skiboard/aboutus), [용평 공식 22/23 지도](https://www.yongpyong.co.kr/upload/kor/winter_trail_map.pdf)의 넓은 베이스·분기/합류·측면 리프트를 참고했다. 과거 PDF를 현재 운영 지도라고 표현하지 않으며, 실제 코스를 복제하지 않았다.

초급 리프트 끝 10%에 남아 있던 3.8m 깊이의 지형 절삭은, 끝 26%부터 부드럽게 줄이고 마지막 10%에서는 추가 절삭이 사라지게 수정했다. 의자와 지면의 최소 0.6m 간격은 유지하며 하차장 주변 높이 차이 검사를 추가했다. 조경 나무 전구는 원래 모양/색과 별개인 밝기 계수로 강화했다. 메인 소원 트리에는 이 계수를 적용하지 않는다.
