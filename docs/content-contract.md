# 지식 연구소 콘텐츠 계약 v3
완성 콘텐츠는 JSON 배열로 저장. 한국어. 날짜 2026-11-14. 최소 6개 분야, 전체 60개. 대표 콘텐츠 12개는 representative:true.
필드: id, title, field (과학/생명/논리/확률/역사/언어/경제/미디어/기술 중 하나), room (curiosity/perspective/logic/probability/garden/memory), type (왜 그럴까/직관 뒤집기/두 가지 관점/근거 찾기/논리 퍼즐/확률 실험/오류 탐정/다른 상황에 적용하기/짧은 복습), difficulty (1,2,3), minutes (3~8), objective, prerequisites (문자열 배열), situation, question, conditions (배열), options (문자열 배열 3~4개), answer (정수 index), judgment (판정 설명), hints (단계별 2개), core (핵심 문단 2~4문장), steps (배열 [{title,text}], 3개 이상), wrongReasons (선택지별 해설 배열, 정답 포함), application ({situation,question,options,answer,explanation}), boundaries (조건 변화와 한계), connections (개념 문자열 배열), sources ([{title,url,locator,support}]), verification ({status:'source-checked',reviewed:'2026-11-14',note}), representative (불리언).
추가: evidence ({text,prompt}) 새 증거를 보고 답을 수정하는 질문. perspectives ([{name,claim,evidence,assumptions,scope,limit}]) 두가지관점에 필수. distinction ('사실 판단'/'가치 판단'/'정보 부족')와 reflection (추가정보가 판단을 바꿀지 질문). simulation ({kind:'coin',p:0.5}|{kind:'sampling'}|{kind:'monty'}|{kind:'graph'}|{kind:'bridge'}|{kind:'seasons'})는 정확히 해당 유형의 질문에서만. 모든 퍼즐은 충분한 조건과 유일해/복수허용 구분.
중요: 직접 웹에서 열어 검토한 신뢰할 수 있는 원 출처를 사용. 한 출처를 여럿 문제의 기반으로 사용해도 되나 locator와 support로 각각 연결. 저작물 복사 대신 독자적인 상황/해설. 확인하지 않은 URL/검토 상태를 만들지 말 것. 생성형 AI 검토는 인간 전문가 심사와 구분. 사실확인 범위/단순화 가정을 note에 기록. JSON 외 별도 검증 메모와 URL 목록을 docs/에 저장. 파일별 총 20개, 대표 4개 먼저 완성하고 중간 보고. 준비되지 않은 항목은 채우지 말고 이유 보고.
