# v59 — 기기 호환·공연·채팅 수정

## 확인한 원인

장식 전체삭제: 관리자 목록은 최신 160개, 삭제 확인은 오래된 160개만 조회했다. 160개 초과 시 변경하지 않아도 revision이 달라 거절됐다. 관리자 화면은 최신 160개만 표시하면서 전체 수량과 ID revision으로 확인하고, 확인된 전체 snapshot만 백업 후 삭제한다. 그 뒤 추가된 장식과 기존 소원 글은 보존한다.

음악: 220ms 이상 어긋날 때 매 프레임 `currentTime`을 바꿨고 play 완료 때도 다시 seek했다. 느린 decoder에서 미완료 seek를 반복하는 문제가 재현됐다. 최초/복귀는 한 번 맞추고, `seeking` 또는 readyState<3 때는 기다린다. 800ms 이상 오차가 1.2초 지속됐을 때만 보정하고 최소 2.5초 간격을 둔다. 실제 iPhone 문제의 모든 원인이라는 확정은 아니며 단말 재확인은 필요하다.

채팅: HTTP로 저장한 내용이 상대방의 다음 pose 응답 때 전달됐다. 검증된 채팅을 같은 공간의 접속자에게 즉시 push하고, HTTP 응답과 중복 수신해도 한 번만 표시한다. 말풍선은 양쪽 모두 서버 시각 기준 남은 지속시간을 적용한다. 이동 보간 지연은 채팅에 적용하지 않는다.

로딩: SVG를 매 RAF에 그리는 방식은 동기 3D 준비 중 정지한다. 네이티브 animated WebP는 메인 스레드가 1.5초 멈춰도 compositor에서 15개 다른 프레임이 관찰됐다. PNG 로고·WebP 트리는 sRGB 픽셀과 지정 색을 사용한다. Samsung 자동 다크의 SVG 색 변환 가능성을 피했으며 `color-scheme:only light`·`forced-color-adjust:none`을 해당 브랜딩에 한정한다. 실제 Samsung 강제 다크는 이 환경에서 재현하지 않았다.

## 공연 흐름

후반 좌우 한 쌍의 회전만 유지하며 중심에서 외곽으로 확대한다. 지상 분수는 회전하지 않는다. 중간 발사 간격 3.8→3.0초, 기존 음악 강세와 장면 구분은 유지한다. 마지막 HAVE A GOOD DAY는 2.6초 상승 궤적을 남기고 동일 중심에서 0.55초 동안 펼쳐져 잠깐 읽힌 뒤 분산·낙하하며 2.8초 안에 사라진다. 하트·저품질 연기·금색 교차 형상은 추가하지 않았다.
