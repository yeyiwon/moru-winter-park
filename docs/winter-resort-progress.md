# 겨울 세계 개편 · 2026-11-16

기존 배포 프로젝트를 수정했다. 별도 데모나 새 캐릭터로 대체하지 않았다.

## 재사용한 기반
- `companion.js`: 기존 뽀송 캐릭터, 털, 눈, 산타모자, 스키·썰매 모델을 확장.
- `park.js`, `movement.js`, `navigation.js`: Three.js 렌더링, 키보드·터치 이동, 경로 탐색 유지.
- `app.js`, `learning-core.js`, `content/`: 기존 82개 질문, 해설, 학습 기록 유지.
- `weather-clock.js`, `world-time.js`, `social.js`, `server/api.js`: 서울 날씨, 현실 시간, 기존 동행 기능 유지.

## 이번 구현
- 독립 소원나무 섬과 연결 다리. 놀이공원 중앙을 가리던 트리 이동, 입체 가지와 장식 재구성.
- 지름 288의 산악 섬, 정상 높이 약 104, 길이 약 168의 주 활강 구간. 지형·이동·리프트가 같은 높이 데이터를 사용.
- 별도 온천 섬, 넓은 노천탕, 편백 휴양관과 휴식 장소.
- 위를 올려다보는 카메라 범위, 달리기, 실제 동선에 맞춘 길, 부드러운 해·달.
- 산타모자·핀·안경·겨울 장비 조합. 고글과 선글라스, 스키와 보드는 각각 상호 배타적. 나머지는 동시 선택 가능.
- 장비가 없으면 리프트 탑승 시 스키·부츠 및 고글 자동 장착. 장비 조건을 갖춘 뒤에만 탑승.
- 캐릭터 비율에 맞는 리프트 좌석·등받이·안전바, 앉은 자세, 정상 하차.
- 스키 직접 조향: A/D 또는 좌우 방향키. S/아래 방향키 감속. 터치는 이동 패드. 경사 가속, 눈길 가장자리 감속, 지면 기울기 반영, 속도·완주 기록·기기 내 최고 기록.
- 기존 동행 API에서 장비 조합과 산악 높이 상태 전달.

## 검증
- `npm test`: 87개 통과. 기존 학습·이동·모델 검증, 직접 조향/감속, 장비 조합, 좌석 자세 검증 포함.
- `npm run build`: Worker와 정적 파일 번들 생성.
- 로컬 두 개의 독립 세션으로 장비 조합 전달, 리프트 고도, 퇴장, 잘못된 위치/세션/요청 출처 거부 확인.
- 실제 브라우저에서 트리 섬, 리프트 탑승/정상 도착, 스키 출발/조향, 커마 동시 착용 확인.
- CPU 모델 검사는 실제 GPU 프레임 측정과 구분. 저사양 모바일과 다수 접속 부하 검증은 남아 있음.

## 남은 단계
기존 동행은 수동 입장과 1초 간격 HTTP 갱신 방식이다. WebSocket, 신고 및 영구 채팅 기록은 아직 구현하지 않았다. 채팅 시 게스트 입장과 현재 세션의 방문자 차단은 추가했다.
관람차와 회전목마는 움직이는 배경이며 아직 탑승 기능이 없다. 새로운 퍼즐·미니게임도 아직 추가하지 않았다.
스키는 캐주얼 경사·조향 시뮬레이션이며 정교한 강체 물리, 넘어짐 애니메이션, 장비별 별도 물리 모델은 남아 있다. 현재 지형과 건물은 직접 만든 절차적 모델이며 상용 에셋 수준의 최종 아트 완료로 간주하지 않는다.

## 추가 개편 — 음악 정원과 따뜻한 휴양 공간
- 거울 포털, 시계탑, 톱니바퀴·배 장식을 제거하고 구역 이름과 남은 충돌도 정리.
- 거대한 하프·건반 조형물 대신 목재 캐노피, 피아노, 차임, 벤치가 있는 음악 정원. 기존 소리 비교·피아노 재생·학습 기능 유지.
- 다리의 판재, 난간, 기둥, 눈 덮인 연결부를 재구성하고 산책로에 석재 줄눈과 가장자리 표현 추가.
- 온천: 따뜻한 조명·물빛·수증기·수건 바구니, 두 탕 입욕과 WASD 이동/퇴장.
- 찜질방: 실내 입장, 벤치에 앉기, 매트에 눕기, 차 마시기와 각각의 자세/시점. 이용 중 장비를 벗고 수건을 쓰며, 종료 시 커마 장비 복원.
- 새 입욕·휴식 상태를 기존 동행 연결에 반영. 서버에서 탕 범위와 좌석 높이 검증.
- 검증: 전체 89개 통과, 마지막 동작/경로/입욕 검증 8개 재통과. 실제 브라우저에서 입욕·이동·퇴장·눕기·차 마시기·음악 정원 확인. 두 접속의 다섯 이용 상태 동기화와 잘못된 입욕 좌표 거부 확인.

## 직접 타는 스키와 공간 채팅
- 약 32m 폭의 실제 평탄 지형과 정상 이동, 터미널 밖 하차. 출발 위치를 유지하고 W로 밀어야 시작. A/D 조향과 S 감속, 경사 가속과 회전 기울임. 중앙선을 자동 추종하지 않는다.
- 근처 시설 위에 E/F/G/H 상호작용 버튼, 클릭·터치 지원. 모바일 스키 조향/출발/감속 버튼.
- 가로 보드, 독립 헬멧, 곡면 단일 렌즈 고글. SMITH I/O MAG·Vantage 형태 참고.
- Enter 또는 채팅 버튼으로 입력. 같은 공간에서 1초 presence 갱신으로 최근 메시지 전달, 6.5초 말풍선, 화면 내 20개 로그. 서버에서 세션·길이·전송 간격 검사. 영구 대화 보관 기능은 아니다.
- 검증: 전체 91개 테스트 통과. 브라우저에서 정상 하차·단축키·장비 조합·말풍선, 390×844 모바일 조작 버튼 확인. 두 세션 간 채팅 전달·길이 제한·전송 간격·인증 검사 통과. 실제 모바일 기기와 다수 사용자 부하는 미검증.

## UI 간소화와 스키 시야 보정
- 회색 채팅·시설·주행 패널 배경 제거. 메시지 입력은 밑줄, 전송과 채팅 열기는 SVG 아이콘. 접근성 이름과 44px 터치 영역 유지.
- 스키 진행 방향 추적, 앞쪽 경사면 주시, 속도에 따른 소폭 시야각 변화, 카메라–캐릭터 사이 지형 높이 검사. 정상에서는 드래그로 바꾼 각도 유지.
- 넓은 슬로프 표면을 가로 방향으로 세분화해 가장자리 사이의 평면이 캐릭터를 덮는 현상 수정.
- 전체 91개 검사 통과. 런타임 검사에 조향 후 카메라의 뒤쪽 위치와 전방 시선 검증 포함.

## 공동 트리와 자연스러운 상호작용
- 같은 공간의 공동 트리: 볼/별·3색 선택 후 트리 클릭 또는 +로 장식. 서버 저장, 2초 동기화, 공간별 160개 한도, 세션 소유 마지막 장식 취소. 기본 트리는 조명만 남기고 기존 고정 볼 제거.
- 작은 캡슐 채팅, 전송 후 입력창 접힘, 말풍선/화면 로그 6.5초 후 제거. 영구 대화 기록은 제공하지 않음.
- 눈 위 양발 자국: 7초 수명, 초기 2초 후 점차 소멸. 40개 인스턴스 재사용, 다리·돌길·휴양관 실내 제외.
- 앉기/눕기/차/쉬기 중 키보드·조이스틱·바닥 클릭 이동으로 해제. 좌석 장애물 밖의 가까운 보행 위치에서 이어 걷기. 입욕 중에는 기존 탕 안 이동 유지.
- 주요 산책로·온천·트리 광장·리조트 입구의 평면 색 띠를 눈에 일부 묻힌 둥근 석재로 교체.
- 두 세션의 트리 공유·저장·공간 격리·취소 소유권·입력 검증 확인. 브라우저에서 채팅 자동 접힘, 트리 꾸미기, 발자국, 이동에 의한 휴식 해제 확인.
- 최종 검증: 전체 92개 테스트 통과(휴식 이동 해제·발자국 교대/만료 포함).

## 연속 눈길과 분리된 슬로프
- 조각식 포장 제거. 경로들을 하나의 거리장으로 합친 눌린 눈길과 부드러운 경계. 놀이공원/주변 섬/온천/트리/리조트 적용. 채팅 캡슐 배경을 거의 투명하게 조정.
- 정상 고도 72m, 넓은 하차 테라스에서 옆으로 돌아 출발해 베이스로 내려오는 S 코스. 중앙선에서 역경사 없이 최대 기울기 약 0.667.
- 리프트 왕복선은 왼쪽 별도 구역. 주행부 안전 경계와 최소 6m 이상 이격, 출발/하차 및 베이스 접근 동선 분리.
- 스키는 산 지형 자체 위를 주행. 별도 흰색 판/줄무늬 오버레이 제거.
- 가장자리 접촉 시 조향 잠금 제거, 속도를 줄이면서 안쪽으로 복귀 가능. 360도 조향·진행 방향 경사에 따른 가속/감속, 회전 방향에 맞춘 캐릭터 기울임.
- 검증: 전체 94개 통과. 실제 브라우저에서 정상 진입·조향·감속·베이스 도착 및 눈길/투명 채팅 확인.
