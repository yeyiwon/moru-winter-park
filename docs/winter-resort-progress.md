# 겨울 세계 개편 · 2026-11-16

기존 배포 프로젝트를 수정했다. 별도 데모나 새 캐릭터로 대체하지 않았다.

## 재사용한 기반
- `companion.js`: 기존 뽀송 캐릭터, 털, 눈, 산타모자, 스키·썰매 모델을 확장.
- `park.js`, `movement.js`, `navigation.js`: Three.js 렌더링, 키보드·터치 이동, 경로 탐색 유지.
- `app.js`, `learning-core.js`, `content/`: 기존 82개 질문, 해설, 학습 기록 유지.
- `weather-clock.js`, `world-time.js`, `social.js`, `server/api.js`: 서울 날씨, 현실 시간, 기존 동행 기능 유지.

## 이번 구현
- 독립 소원나무 섬과 연결 다리. 놀이공원 중앙을 가리던 트리 이동, 입체 가지와 장식 재구성.
- 지름 288의 산악 섬, 정상 높이 약 104, 길이 약 168의 주 활강 구간. 지형·이동·리프트가 같은 높이 데이터를 사용.
- 별도 온천 섬, 넓은 노천탕, 편백 휴양관과 휴식 장소.
- 위를 올려다보는 카메라 범위, 달리기, 실제 동선에 맞춘 길, 부드러운 해·달.
- 산타모자·핀·안경·겨울 장비 조합. 고글과 선글라스, 스키와 보드는 각각 상호 배타적. 나머지는 동시 선택 가능.
- 장비가 없으면 리프트 탑승 시 스키·부츠 및 고글 자동 장착. 장비 조건을 갖춘 뒤에만 탑승.
- 캐릭터 비율에 맞는 리프트 좌석·등받이·안전바, 앉은 자세, 정상 하차.
- 스키 직접 조향: A/D 또는 좌우 방향키. S/아래 방향키 감속. 터치는 이동 패드. 경사 가속, 눈길 가장자리 감속, 지면 기울기 반영, 속도·완주 기록·기기 내 최고 기록.
- 기존 동행 API에서 장비 조합과 산악 높이 상태 전달.

## 검증
- `npm test`: 87개 통과. 기존 학습·이동·모델 검증, 직접 조향/감속, 장비 조합, 좌석 자세 검증 포함.
- `npm run build`: Worker와 정적 파일 번들 생성.
- 로컬 두 개의 독립 세션으로 장비 조합 전달, 리프트 고도, 퇴장, 잘못된 위치/세션/요청 출처 거부 확인.
- 실제 브라우저에서 트리 섬, 리프트 탑승/정상 도착, 스키 출발/조향, 커마 동시 착용 확인.
- CPU 모델 검사는 실제 GPU 프레임 측정과 구분. 저사양 모바일과 다수 접속 부하 검증은 남아 있음.

## 남은 단계
기존 동행은 수동 입장과 1초 간격 HTTP 갱신 방식이다. 자동 게스트 입장, WebSocket, 채팅/신고/차단, 공동 트리 장식 및 영구 저장은 아직 구현하지 않았다.
관람차와 회전목마는 움직이는 배경이며 아직 탑승 기능이 없다. 새로운 퍼즐·미니게임도 아직 추가하지 않았다.
스키는 캐주얼 경사·조향 시뮬레이션이며 정교한 강체 물리, 넘어짐 애니메이션, 장비별 별도 물리 모델은 남아 있다. 현재 지형과 건물은 직접 만든 절차적 모델이며 상용 에셋 수준의 최종 아트 완료로 간주하지 않는다.
