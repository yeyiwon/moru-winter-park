# v62 료칸 족욕장 석재

2026-11-24. 료칸 족욕장의 테두리와 옆면 돌만 바꾼 변경이다. 조명, 물, 창밖 풍경, 캐릭터는 그대로다.

## 원인

족욕장 테두리가 긴 판 4개였고 옆면에 달걀 모양 돌 12개가 박혀 있어, 석조 욕조가 아니라 바닥에 놓인 상자로 읽혔다.

## 선택 이유

Visual Revision 실험(`experiment/visual-revision-ryokan`)에서 조명·물·창밖 풍경·석재를 함께 고쳤고, 구현과 분리된 검수에서 석재만 "통합 가능" 판정을 받았다. 나머지는 "수정 후 통합"이라 실험 브랜치에 남겼다. 실험 전체 기록은 그 브랜치의 `docs/visual-revision-ryokan.md`에 있다.

## 변경 파일

- `dist/ryokan-footbath.js` (신규): 모따기 있는 갓돌 26개(길이·높이·각도에 작은 편차, 12mm 줄눈)와 강돌 25개.
- `dist/interior-world.js`: 기존 테두리 판 4개와 달걀 모양 돌 12개를 위 함수 호출로 교체.

바깥 치수, 테두리 높이 0.60, 수면 0.50은 그대로다. 좌석, 충돌, 물 셰이더 영역, 레이아웃 데이터는 바꾸지 않았다.

## 실제 검증

- `npm test` 596/596 통과, `npm run check` 345개 모듈 구문 통과, `npm run build:vercel` 성공.
- 료칸 정적 자산: 98 메시, 178,369 → 179,277 삼각형(한도 100 / 180,000).
- 배포 예산: core 37,364,147B / 37,748,736B, 코드 gzip 1,185,263B / 1,280,000B.
- 같은 카메라·아바타·좌석의 전후 캡처: `qa/footbath-v62/`. 색상 패스 Draw calls는 seat-default 90 → 90, footbath-hero 104 → 104로 같고, 삼각형은 +908이다.
- 캡처 환경은 헤드리스 Chrome + 소프트웨어 렌더러, 1440×900, 품질 medium이다.

## 알려진 한계

- FPS, 프레임 시간, GPU 메모리: UNKNOWN. 실제 GPU와 실물 모바일에서 재지 않았다.
