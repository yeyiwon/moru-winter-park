## 공간과 분위기

작은 독립 수족관 계획을 폐기하고 북쪽 벽 42m 중 **38.6m(92%)**, 높이 **8.8m**, 실제 깊이 **8.4m**인 수조를 새로 구성했다. 외부 료칸 건물은 그대로다. 수조는 실내 뒤편 공간을 쓰며 앞 유리·프레임·충돌 범위가 `ryokan-aquarium-layout.js`를 공유한다. 높은 칸막이를 낮추어 입구, 다다미, 차 자리에서도 전체 수조를 볼 수 있다. 관람 팝업·퀴즈는 없다.

수중 모래 지형, 높이가 다른 암석과 동굴, 유목, 곡면 잎 수초를 배치했다. 물고기는 서로 다른 깊이의 느슨한 여섯 무리와 독립적으로 이동하는 큰 물고기로 나뉜다. 개별 위상·높이·속도와 크기별 분리 거리를 사용해 한 덩어리로 뭉치는 현상을 줄였다. 120초 표본의 위치 폭은 x 32.43 / y 6.24 / z 5.65m였다. 수면 파동·바닥과 바위의 코스틱·수중 빛줄기·유리 미세 반사를 공유 시각으로 갱신한다.

외부용 전역 조명이 실내에서도 강하게 남던 원인을 고쳤다. 첫 어두운 시안은 사용자가 귀신의 집처럼 느낀다고 지적하여 폐기했다. 최종판은 따뜻한 반사광을 올려 천장·벽·나무 바닥이 읽히게 하고, 수조의 청록색과 차·조리대의 앰버 조명으로 대비를 만든다. 수조가 방 전체를 파랗게 덮지 않는다. [최종 입구 화면](../qa/ryokan-v57/hall.png).

등갓에는 곡면 종이와 대나무 골조, 벽에는 회벽·와시 질감, 천장에는 목재 골조, 다다미에는 짜임을 넣었다. 셰프 뒤 조리대·그릇·차 도구·찜질 돌도 세부 형상을 보강했다. 창문은 외부 월드를 뚫는 구멍이 아닌 깊이 있는 별도 창틀과 설경이다. 산·여러 겹의 눈 덮인 숲·세 깊이의 눈발이 보이며, 일부 창문에서 나무가 사라지던 좌표 범위를 수정했다.

## 좌석·물·음식

- 차 벤치, 찜질 벤치, 다다미 앞뒤, 차 방석, 족욕 양측 등 료칸 벤치 시설 **9곳 × 2석**과 기존 오마카세 **3석**을 같은 예약·점유 시스템에 연결한다. 자리 이동과 동시 점유 충돌 검사를 유지한다.
- 족욕은 발 모양을 늘리지 않고 앉은 높이와 보통 크기의 발 위치를 조정했다. 직사각형 돌 수조에 맞춘 수면 경계, 실제 이용자 위치의 잔물결, 은은한 물빛을 쓴다.
- 뜨거운 돌, 주전자, 족욕, 손에 든 찻잔에는 천천히 말려 올라가는 김이 생긴다. reduced motion과 품질 단계가 적용되며 각 발생원은 정해진 GPU 입자 버퍼를 재사용한다.
- 셰프는 사용자 의상 목록에 없는 흰 조리복·앞치마·모자를 입은 몽실한 전용 캐릭터다. 기존 서버 서빙 시각을 기준으로 준비→접시 이동→손님에게 건네기→식사 순서를 공유한다.
- 연어·참치·방어·도미·고등어 초밥 중 서버가 정한 서빙 시각의 결정적 해시로 선택한다. 셰프 접시와 손님 접시가 같은 생선이며, 늦게 입장해도 같다. 무작위 선택이므로 연속 중복이 우연히 발생할 수 있다.
- 가까이 오면 셰프가 앉도록 안내하고, 준비·서빙·식사 단계에 **실제 제공된 생선 이름**으로 소개한다. 살결, 얇은 지방 무늬, 밥알, 시소 잎, 생강, 도자기와 젓가락을 재사용 가능한 다섯 접시로 구성했다.

## 비용을 제한하는 구조

물고기는 5개의 InstancedMesh, 품질별 28/48/72마리다. 수초 40/80/120개, 거품 20/40/64개를 재사용한다. 보이지 않는 수조는 업데이트 빈도를 낮추며, 비활성 실내는 렌더링하지 않는다. 수면은 GPU 파동, 코스틱은 저비용 셰이더이고 추가 실시간 반사 렌더러는 없다. 수조와 작은 조명은 기존 최대 6개(모바일 4개) 조명 풀에서 선택된다. 초밥 템플릿은 5종·최대 35개 공유 geometry로 제한한다. 새 production dependency나 D1 migration은 없다.

## 실시간 원인과 수정

WebSocket에서도 HTTP용 **1,100ms** 보간 지연을 사용해 움직임이 늦게 보이던 경로를 분리했다. WebSocket은 180ms 버퍼, HTTP fallback은 기존 1,100ms를 쓴다. 정지 상태의 수신 확인 간격도 750→200ms로 줄인다. 멀리 있는 사람의 이동은 1초 간격, 가까운 최대 32명은 빠른 갱신을 유지한다. 채팅·외형·활동 변경과 정지는 거리와 무관하게 바로 전달한다.

100명 부하에서 지연된 이동 패킷이 쌓여 한꺼번에 도착하는 실패를 확인했다. 클라이언트 미응답 패킷을 **2개**로 제한하고 응답 후 가장 최신 위치만 보내도록 했다. 거절 후에는 짧게 쉬고 재개한다. 서버의 속도 제한을 완화하거나 오류를 숨기지 않았다. 실패 원본은 `qa/final-v57/load-before-backpressure.json`, 수정 후 결과는 `load.json`에 보관한다.

관리자 상태에 클라이언트가 보고한 왕복 평균/p95, 서버 처리 평균/p95, 재연결 수·비율, DB 상태, realtime 버전·규격 일치를 추가했다. 보고값은 유효 범위·5초 간격·300개 표본으로 제한한다. 클라이언트 보고 RTT는 신뢰할 수 있는 과금/보안 지표가 아니며 운영 참고값이다. 새 로그에 채팅 내용이나 비밀 값은 기록하지 않는다.

## 추가 마감과 최신 요청 반영

- 료칸: 등롱의 살·황동 마감·매달린 끈, 천장 격자, 청자 꽃병과 매화 가지, 작은 소나무와 수건을 기존 가구 위에 배치했다. 통로와 좌석의 물리 배치는 유지했다. 식기 유약과 초밥의 쌀알·생선 결을 보강했다.
- 안내: 셰프가 서버가 정한 음식 이름과 준비/전달 단계를 안내한다. 안내 말풍선과 좌석 버튼 사이에 14px 간격을 두고 NPC 메시지 색·모서리를 공유한다. 천문대 과학자도 근처에서 8초 동안 간단히 관람·퀴즈를 안내하며 이동 시 사라진다.
- 놀이공원: 촘촘한 돌 포장 시안은 후속 요청에 따라 제거했다. 기존 `parkWalkways` 안에 납작한 부정형 디딤돌 **43개**를 크기·방향·간격을 달리해 드문드문 놓고, 돌과 돌 사이의 눈 여백을 남긴다. 연속 테두리는 없다. 교차로는 겹쳐 그리지 않는다. 화단 세 곳은 `parkFlowerbeds`를 모델·충돌이 함께 사용한다. 수국은 4장의 꽃받침을 가진 작은 꽃 38개가 한 꽃송이를 이루며 가지와 곡면 잎을 별도로 표현한다. 가판대 접근점 충돌을 검사하고 화단 위치를 조정했다.
- 중간 정류장: 지형을 낮춰 파내던 방식 대신 위쪽 어깨 높이에 흙을 채우는 평탄지를 사용한다. 스키 슬로프의 높이와 월드 크기는 유지한다. 달의 방위는 유지하고 고도를 높여 8개 검증 시점의 산 가림을 없앴다.
- 공연: 긴 금빛 잔광, 더 큰 상층 불꽃, 별 모양 성 표면 조명과 마지막 색 대비를 보강했다. 서버 시계와 seed, 24개 shell pool은 유지한다. Trepak을 세 번째 공연으로 추가하며 기존 두 원본은 변경하지 않았다.

### 추가 음원 — Trepak

- 곡: Pyotr Ilyich Tchaikovsky, The Nutcracker Suite, Russian Dance (Trepak).
- 연주 제작: Philip Milman; Lud and Schlatts Musical Emporium (Ludwig Ahgren, Jschlatt).
- [파일·출처·라이선스](https://commons.wikimedia.org/wiki/Special:Redirect/page/123487426), [원 게시물](https://www.youtube.com/watch?v=CcHo03GzMN8), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
- 2026-11-20 Commons API의 해당 파일 description, credit, artist, LicenseShortName, LicenseUrl을 확인했다. 원곡 public domain 여부만으로 녹음의 권리를 가정하지 않았다.
- 원본 WAV: 48kHz stereo 24-bit, 3,564,062 sample frames, 74.2512917초. SHA-256 `1545f095e0d3981b918a2fdeeff95e6e71552377c2300ec71a9ad067716933ab`.
- 배포 AAC: 192kbps 목표, 전체 길이 유지, 절단·속도 변경 없음. SHA-256 `3291948df42a82011d2a9f34f6807a314c83cb41af4b11eae5ff0d76cfa58221`. 소리 설정에 제작자·라이선스·AAC 변환을 표시한다.
- 분석용 22.05kHz mono PCM의 10ms RMS 상승으로 attack 후보 187개를 추출했다. 전체 mono RMS −19.861dBFS. `trepak-analysis-v57.json`은 기계적 후보이며 공인 악보/BPM 또는 청취 평가가 아니다. 168 BPM은 조명 설계용 추정값이고 발사 타이밍은 측정된 attack에 맞춘다.
- 파일이 약 1.75MB 늘어나 공연 전용 지연 로딩 예산만 8→10MiB로 늘렸다. 일반 월드/code 예산은 유지한다. 원본 파일 독립 다운로드 상품은 만들지 않는다.

### 조작·안내 최종 수정

- NPC 메시지는 화면 **하단 중앙**으로 통일한다. 천문대·트리 안내, 광장 신청, 셰프의 준비/전달 안내가 같은 하단 여백을 사용한다. 모바일은 조이스틱 위 170px, 데스크톱은 108px이며 불꽃놀이 알림은 기존 **상단**에 유지한다.
- 아이스크림·팝콘·스파클러는 단일 버튼과 장소 이름이 같아 제목이 숨겨졌었다. 장소 이름을 ‘… 부스’로 명시해 제목을 유지한다.
- E 또는 모바일 손 소품 버튼을 누르는 동안 스파클러를 흔든다. 이동하면서 사용할 수 있고 키/포인터 해제, 취소, 창 이탈, 패널 열기, 지역 이동에서 멈춘다. `sparkler-wave`를 기존 검증된 활동 프로토콜로 동기화한다.
- 비눗방울 버튼은 48px 너비와 56px 최소 높이가 충돌했다. 너비/높이/최소 크기를 모두 48px로 일치시켜 누르는 중에도 원형을 유지한다.
- 스키 중 조이스틱을 가리던 전용 방향키 규칙을 제거했다. 원래 조이스틱의 출발·조향·제동과 점프/제동 버튼을 유지하며 중복 조작판, 속도 안내, 경로 복귀 버튼을 숨기거나 제거한다. 스키 종료는 유지한다.
- 채팅 바깥을 누르면 미전송 초안과 입력창을 취소한다. 월드 클릭은 이때 이동으로 이어지지 않으며 입력창·전송 버튼·채팅 기록 내부 클릭은 취소하지 않는다.
- 실내 전환은 반투명 배경만 먼저 페이드하는 단계를 없애고 트리/Loading 문구가 있는 전체 레이어를 즉시 표시한다. 전환 중 NPC·시설 안내를 숨겨 로딩 앞에 잠깐 끼지 않도록 한다.
- 공연은 선명한 빨강·파랑·보라를 확대하고 일부 상층 폭죽에 0.38초 뒤 낮은 별 불꽃이 답하는 두 겹 연출을 넣었다. 흰색/금색으로 지나치게 희석하던 비율을 줄였고 기존 24-shell 고정 풀을 유지한다.

검증은 `qa/final-v57/controls`, `audio`, `room` 및 공연 보고서에 기록한다. 실물 휴대폰·Windows의 GPU/키보드/오디오 정책은 미검증이다.
