# 내가 사랑하는 겨울 — v25 변경 및 검증 기록

## 상부 리프트와 스키장

상부 리프트 승강장을 정상 화장실 뒤쪽 `(23, -361)`로 옮겼다. 음식 부스 중심과 약 13.2m, 화장실 중심과 약 12.7m 떨어져 있다. 실제 탑승 지점은 `(28.15, -356.70)`이며, 정상 하차장부터 폭 6.5m의 완만한 연결로로 접근한다. 길과 문, 조명, 기둥, 상호작용 위치를 같은 배치 데이터에 맞췄다. 상부 리프트 종점은 `(1, -395)`로 두어 슬로프를 가로지르지 않게 했다.

상부 하차 시 종전 시점은 터미널 뒤를 향했다. 도착 방향을 조정하고 실제 모델에 대한 시야 검사를 추가했다. 눈 지형의 분할 수도 높여 보행 높이와 렌더링된 설면의 차이를 줄였다. 리프트 의자는 캐릭터와 케이블 간격에 맞춰 넓히고, 장식용 의자가 실제 탑승 의자와 겹치지 않게 했다.

스키는 입력 dead zone, 조향 반응, 가장자리 감속을 수정했다. W로 출발하고 좌우 입력으로 진로를 직접 바꾸며 S로 감속한다. 자동 코스 추종은 사용하지 않는다.

주요 파일: `dist/resort-layout.js`, `alpine-resort.js`, `winter-rides.js`, `winter-experience.js`.

## 월드와 시설

- 놀이공원을 하나의 넓은 섬으로 유지하고 다른 구역과 연결되는 다리를 넓혔다. 이동 가능 영역, 섬의 실제 지형, 지도와 경로가 같은 배치를 참조한다. 기존의 부드러운 눈길 재질은 유지했다.
- 범퍼카와 회전컵의 모델, 이동 목적지, 이용 모드와 관련 코드를 제거했다. 해당 구역은 넓은 통로와 벤치·조명이 있는 포토 가든으로 변경했다.
- 관람차를 아이스 블루·샴페인 골드 프레임과 12개의 2인 곤돌라로 변경했다. 좌석 간격은 2.35m이며, 머리 위 공간과 곤돌라 간 간격을 검사한다.
- 회전목마의 플랫폼, 말의 +Z 방향, 캐릭터 위치를 함께 확인하여 회전 방향을 수정했다.
- 온천과 온실에 수면 반사·caustics, 낮게 흐르는 수증기, 반딧불, 상단 리본과 바닥 조명을 추가했다. 품질 설정과 정지 설정을 따르고 보이지 않는 실내 효과는 갱신하지 않는다.
- 아이스링크 입구는 4.8m 폭으로 확보하고 촘촘한 기둥과 상부 와이어를 줄여 낮은 유리 난간으로 바꿨다. 기존 스케이팅 기능을 유지한다.

주요 파일: `world-layout.js`, `connected-terrain.js`, `world-art.js`, `world-paths.js`, `festival-layout.js`, `festival-rides.js`, `ferris-model.js`, `carousel-model.js`, `retreat-atmosphere.js`, `spa-resort.js`, `winter-retreat.js`, `interior-world.js`.

## 카메라와 멀티플레이

확인된 문제는 시설 이용 중/실내에서 기존 카메라 가림 검사가 비활성화되었다는 것이다. 이제 실제 월드·실내 메시를 대상으로 카메라 근평면 주변의 네 방향을 검사하고, 장애물 앞까지 당긴 뒤 부드럽게 원래 거리로 복귀한다. 대형 정적 메시의 삼각형은 공간별로 나누어 검사 비용을 줄였다. 회전목마, 관람차, 리프트와 스키에는 각 시설에 맞는 추적 방향을 적용했다.

카메라에 실제로 걸리는 지정된 곤돌라/의자 부품만 잠시 투명해진다. 공유 머티리얼을 직접 바꾸지 않고 복제하며, 이용 종료 시 원래 상태로 복원한다. InstancedMesh도 인스턴스 전체 경계를 사용한다.

관람차와 리프트는 서버에서 좌석을 원자적으로 배정한다. 두 사람이 같은 출발 시각과 서로 다른 좌석을 사용하며 개별 하차할 수 있다. 예약 만료와 탑승 요청 중 취소를 처리한다. Vercel의 `/api/ride` 전달 경로도 포함했다. 데이터 변경은 추가 테이블을 만드는 `drizzle/0007_shared_ride_seats.sql`이며 기존 테이블/데이터를 삭제하지 않는다.

주요 파일: `camera-clearance.js`, `camera-raycast.js`, `park.js`, `ride-seats.js`, `social.js`, `visitors.js`, `server/ride-api.js`, `server/api.js`, `server/vercel-proxy.js`.

## 브랜딩, UI, 캐릭터, 오로라

- 메인 제목을 ‘내가 사랑하는 겨울’로 변경했다. 로딩은 산과 마을 불빛·눈 입자가 있는 겨울밤 화면이며 실제 에셋/접속 단계에 따라 종료한다. 가짜 퍼센트를 표시하지 않는다.
- 점프 아이콘은 단순한 도약 심볼로 변경하고 이동·감정·점프·채팅의 터치 영역을 분리했다. 탑승 중에는 불필요한 조작 버튼을 숨긴다.
- 지도에 실제 섬/다리/상부 리프트 배치와 시설 미니어처를 반영했다. 지도와 목적지 선택줄을 분리하고 패널 스타일을 통일했다.
- 하트 눈은 폰트 글리프 대신 대칭 SVG를 사용한다. 커마 타일의 아이콘 영역과 라벨 행 높이를 통일했다. 기본 선글라스를 얇은 프레임으로 바꾸고 타원형·캣아이 선글라스, 스카프, 베레모를 추가했다. 기존 모루 몸체의 비율과 복슬복슬한 털은 유지했다.
- 오로라는 세 겹의 길고 얇은 커튼, 부드러운 접힘, 미세한 하단 빛결과 느린 청록·블루 변화로 수정했다. 기존 효과는 높이와 감쇠의 조합 때문에 일부만 드러나 평행선처럼 보였다.

실제 북극광 참고: [NASA 사진 안내](https://science.nasa.gov/feature/nasas-guide-to-finding-and-photographing-auroras/), [NASA APOD](https://apod.nasa.gov/apod/ap150504.html). 사진 에셋을 복사하지 않고 곡면과 셰이더 형상의 참고로 사용했다.

## 검증 범위

자동 검사에는 실제 지형/모델에 대한 이동 경로와 머리·어깨 여유 공간, 상부 하차 시야, 설면 높이, 캐릭터 기하/접지, 다섯 슬로프 완주, 카메라 충돌과 머티리얼 복원, 이동·점프 입력 소유권, 좌석 동시 배정/만료, 기존 소셜 기능을 포함한다. 검사 명령은 `npm test`, 빌드는 `npm run build`와 `npm run build:vercel`이다. 별도 lint/typecheck 스크립트는 없다.

실제 브라우저에서 확인한 범위:
- 원래 모루 외형, 새 브랜딩, 부유섬·연결 다리, 지도.
- 관람차 탑승 시 캐릭터와 빈 옆 좌석이 보이는 시점.
- 기본 리프트 → 정상 → 이동한 상부 탑승 지점 → 상부 리프트 도착.
- 스키 직접 출발, 조향, 제동, 자국과 추적 시점.
- 390×844 화면에서 지도 아래 선택줄 분리, 조이스틱·점프·감정·채팅 영역 비겹침, 커마 미리보기 전체 표시.

최종 전체 검사 **218/218 통과**. 카메라의 인스턴스 경계, 예약 만료 시 안전한 복귀, 탑승 요청 중 취소에 대한 추가 회귀 검사까지 포함한다. 검사 결과 파일은 작업 출력 디렉터리에 보관한다.

미검증/제한:
- 실제 휴대전화에서의 물리적 멀티터치, 두 브라우저의 동시 2인 탑승, 모든 시설/카메라 각도는 직접 확인하지 못했다. 입력/좌석 자동 검사와 구분한다.
- 마지막 단계에서 브라우저 제어 도구를 사용할 수 없게 되어 새 온천·온실 VFX와 최종 선글라스 선택 상태의 추가 화면 검사는 마치지 못했다.
- 측정한 장면은 메시 591개, 머티리얼 215개, 약 393만 삼각형으로 기존 검사 한도 안이다. 이는 CPU에서 장면을 구성한 결과이며 모바일 FPS나 GPU 성능의 증거가 아니다.

이번 기록은 위에 명시한 수정 범위에 대한 것이다. 모든 과거 요청의 시각적 완성도가 사용자 기대를 충족했다고 단정하지 않는다.
