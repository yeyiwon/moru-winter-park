# 투명한 밝은 글래스 UI 보정 — v44

작성일: 2026-11-19

## 원인

앞선 밝은 UI는 패널 배경의 알파가 90%·84%·87%였고 내부 필드도 43%의 흰색을 사용했다. 이 조합이 월드의 색과 실루엣을 대부분 가려, 사용자가 요청한 투명한 유리보다 밝은 불투명 카드에 가깝게 보였다. 어두운 잉크색 글자도 그 높은 배경 불투명도를 전제로 했다.

추가로 일반 버튼의 활성·hover 상태 두 규칙이 `--ui-solid`를 사용해 조작하는 순간 불투명해졌다. 기본 표면과 상호작용 상태를 같은 유리 토큰 계열로 맞출 필요가 있었다.

## 디자인 선택과 실제 변경

밝기는 얇은 흰 반사, 가장자리와 글자에서 만들고, 패널의 색은 뒤에 있는 월드가 충분히 비치도록 조정했다. `ui-system.css`의 공통 토큰을 사용해 설정·지도·커마·관리·채팅·퀴즈·카메라 도구·시설 버튼에 같은 기준을 적용한다.

| 항목 | 이전 값 | 보정 값 |
| --- | --- | --- |
| 패널 그라데이션 알파 | 90% / 84% / 87% | 22% / 10% / 16% |
| 기본 필드의 흰색 알파 | 43% | 5.5% |
| 강한 필드 표면 알파 | 70% | 14% |
| HUD 표면 알파 | 84% | 16% |
| 팝오버 표면 알파 | 96% | 20% |
| 기본 글자 | 짙은 잉크색 | `#F7FBFF` |
| 보조 글자 | 짙은 청회색 | `#E0EAF3` |
| 강조색 | 짙은 청색 | 샴페인 `#FFF0CA` |

- 테두리는 얇은 흰색 반사로 유지하고 내부 그림자를 가볍게 줄였다.
- 밝은 글자의 가독성을 보조하도록 작은 `text-shadow`를 공통 토큰으로 사용한다. 실제 대비는 뒤에 비치는 장면에 따라 달라지므로 고정 대비율이나 접근성 등급을 주장하지 않는다.
- 달리기·비눗방울 등의 활성 상태와 시설 버튼 hover·스키 제동 active 상태에서 불투명 `--ui-solid` 사용을 제거했다.
- 퀴즈 footer의 별도 배경을 투명하게 바꿔 패널 아래에 또 다른 색면이 쌓이지 않게 했다. 퀴즈와 지식집은 공통 유리 표면·글자 토큰을 유지한다.
- 활성 드롭다운 한 곳에는 국소 blur를 허용한다. 펼친 옵션 뒤의 설정 본문이 겹쳐 읽히는 현상을 줄이기 위한 예외다.
- 네이티브 `option`은 브라우저가 불투명 선택창을 그릴 수 있으므로 별도 `--ui-solid-ink`를 사용한다.

## 성능 범위와 fallback

기본 패널 blur는 데스크톱 10px, 모바일 8px, 저사양 렌더 모드 4px다. 저사양 모드에서도 유리의 투명도를 유지하면서 blur 반경을 줄인다. 활성 드롭다운을 제외한 일반 내부 버튼·필드·작은 HUD에 중첩 blur를 추가하지 않는다.

`backdrop-filter` 미지원 또는 `prefers-reduced-transparency: reduce` 환경에서는 불투명한 밝은 표면과 어두운 글자로 함께 전환한다. 이 경우 blur와 텍스트 그림자를 끈다. 밝은 불투명 표면 위에 밝은 글자만 남는 조합을 피하기 위한 fallback이다.

이번 보정은 CSS 표면·색상·합성 범위다. 새로운 3D 렌더러, 셰이더, 월드 조명, 애니메이션 루프, 네트워크 처리 또는 자산 다운로드를 추가하지 않았다. 중앙 퀴즈의 위치, 모바일 터치 영역, 카메라 조절 모드, 좌석 선택·예약·서빙 기능도 변경하지 않았다.

blur 반경을 줄였다는 사실만으로 실측 성능 향상을 확정하지 않는다. 이번 작업에서 실제 기기의 FPS, GPU 시간, 메모리, 발열은 측정하지 않았다.

## 변경 파일

| 파일 | 역할 |
| --- | --- |
| `dist/ui-system.css` | 낮은 알파의 유리 토큰, 밝은 글자, blur 단계, 드롭다운 예외, 네이티브 옵션 및 접근성 fallback |
| `dist/resort-ui-v43.css` | 일반 활성/hover 상태의 불투명 표면 제거, 채팅·시설 표면의 글자 그림자 연결 |
| `dist/quiz-journal.css` | 공통 backdrop·글자 그림자 연결, 투명 footer 유지 |
| `dist/camera-controls.css` | 카메라 도구의 공통 backdrop·글자 그림자 연결 |

`customization.css`, `mobile-ui.css`, `seat-selection.css` 등은 기존 공통 토큰 참조를 통해 색상을 따른다. 로고·브랜딩·월드 배치·료칸/박물관 geometry는 이번 보정 대상이 아니다.
