# 긴급 렌더링·조작 복구 — 2026-11-17

## 범위
이번 본문의 “다른 콘텐츠를 추가하지 않는다”를 우선했다. 오로라, 기존 캐릭터, 모바일 입력/배치, 정상 환승을 수정하고 첨부 문서의 로고·로딩 교체를 반영했다. 첨부 뒤쪽의 부유 섬 재구성, 놀이기구 삭제, 2인 좌석 예약, 대형 실내 확장은 이번 긴급 수정에 포함하지 않았다.

## 확인된 원인과 변경 파일

| 문제 | 확인한 원인 | 수정 |
|---|---|---|
| 몸통 분리·뒤집힘, 초기 카메라 이탈 | 동기식 월드 구성 후 첫 RAF 시간이 `performance.now()`보다 과거가 되면 음수 dt가 착지 강도를 증가시킴. 실제 월드에서 몸통 Y scale 약 -3.7 관찰. 과거 타임스탬프 주입으로 재현 | `dist/park.js`: dt를 0~0.05초로 제한. `dist/companion.js`: 착지 변형 0~1 제한. 원래 메시, 비율, 액세서리 유지 |
| 밤에 털만 떠 보임 | 몸통은 조명 적용, 털은 unlit 재질이어서 밝기가 크게 분리됨. VFX off 비교에서도 발생 | `dist/companion.js`: 털에도 조명 적용, 몸통/털의 약한 야간 보조광 일치. `dist/glow-pass.js`: 후처리 렌더 타깃에도 MSAA 적용 |
| 반복되는 오로라 기둥 | X축 고주파 사인파가 불투명도를 크게 끊고, 역순 smoothstep 사용 | `dist/winter-sky.js`: 변형된 긴 리본 3개, 완만한 비주기 noise, 연속된 알파, 느린 파동. 별도 캐릭터 변형 없음 |
| 점프 중복 입력·화살표 | pointer 소유권이 없고 기존 화살표 SVG 사용 | `dist/game-input.js`: jump pointer 소유권/해제/취소 처리. `dist/index.html`: 도약하는 작은 캐릭터 SVG |
| 감정 버튼이 조이스틱과 겹침 | 조이스틱은 좁은 화면과 coarse pointer에, 감정 버튼은 coarse pointer에만 별도 배치 | `dist/metaverse.css`, `dist/emotes.js`: 공통 반응형 조건, 감정 버튼 독립 배치, 열 때 이동 초기화, 외부 터치/ESC/선택 시 닫기. `dist/world-labels.js`: 하단 조작부 공간 확보 |
| 정상 환승 우회·시설 겹침 | 회전한 터미널과 별개 좌표로 탑승 안내 위치를 잡음 | `dist/resort-layout.js`, `dist/alpine-resort.js`: 열린 진입 축에서 입구 계산, 4.8m 연결 산책로, 트럭 뒤쪽으로 케이블 분리, 실제 기둥 충돌 반영, 상부 하차 대기 공간. `dist/winter-rides.js`, `dist/park.js`: 상부 도착 시 지붕을 피하고 내리막을 보는 시점 |
| 로고·로딩 | 서로 다른 심볼, 서버 연결 단계를 진행 상태에서 누락 | `dist/index.html`, `dist/loading-state.js`, `dist/metaverse.css`, `dist/social.js`: 공유하는 독자적인 육각 크리스털 SVG, 형성/빛 스침/입자/완료 전환, 실제 5단계 진행, 연결 오류 및 재시도. reduced-motion 대응, 별도 WebGL renderer 없음 |

## 실행한 검증
- `npm test`: 192/192 통과(전체 실행 후 상부 도착 시점 회귀 검사 추가).
- 마지막 시점 변경 이후 정상/렌더링 검사 19/19, 메뉴·로딩 검사 3/3 추가 통과. 상부 하차 카메라와 캐릭터 사이에 실제 터미널 메시가 끼지 않는 광선 검사 포함.
- 첫 RAF 시간을 10초 과거로 주입하고 몸통 scale과 카메라 위치가 정상 범위를 유지하는지 검사.
- 로컬 및 원격 캐릭터의 메시·인스턴스 데이터, 정지/걷기/달리기/점프/회전/거리 변화, VFX 비활성/복원 비교.
- 브라우저 실제 월드에서 이동, 점프, 시점 회전, 기본 리프트 탑승 → 정상에서 직접 걷기 → 상부 리프트 탑승 → 상부 하차 확인.
- 실제 렌더링된 터미널 메시를 대상으로 환승 통로의 어깨/머리 높이 충돌 검사 통과. 연결 통로의 높이, 시설 간 간격, 신규 케이블과 서버 좌석 좌표 검사.
- 브라우저 390×844 / 320×568 / 844×390 화면에서 조이스틱·점프·감정·채팅·메뉴 bounding rectangle 겹침 0. 감정 메뉴 열기/선택/닫기, 조이스틱 해제, 점프 확인.
- 조이스틱 이동 + 별도 카메라 pointer + 점프 동시 입력, 다른 손가락의 jump 소유권 해제 방지, pointercancel / blur / lift / pause 초기화를 자동 검사.
- 로고 대칭과 공유, 실제 로딩 단계/중복 이벤트/오류/완료 전환 검사.
- `npm run build`, `npm run build:vercel` 성공. 최종 패키지는 마지막 시점 변경 이후 다시 빌드한다.

## 검증 한계
- 브라우저의 모바일 크기와 합성 pointer 검사이며 실제 iOS/Android 손가락 멀티터치 검증은 아니다.
- 원격 캐릭터 렌더링과 멀티플레이 서버 회귀 검사를 수행했지만 별도 실기기 2대의 동시 접속 부하 검사는 하지 않았다.
- 저사양 모바일에서의 지속 FPS/발열은 미측정이다.
- 사용자 지정 조명색/밝기, 외형, 월드 콘텐츠는 유지한다.
