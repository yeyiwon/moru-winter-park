# v27 — 장식 복원, 동선 단축, 투명 UI

## 적용 범위

- 온실과 내부 진입·상호작용·지도 항목을 제거. 사진 촬영 팝업과 빛의 듀엣 제거. 광장에는 당근을 뺐다가 끼우는 독립 눈사람 배치.
- 스키장 전체를 90m, 온천·링크를 40m 가까이 이동. 리프트·정상·충돌·서버 좌석 검증·음원 위치를 함께 옮겼다. 슬로프 경사와 탑승 좌석 비율은 유지.
- 트리 구역을 30m 당겨 중앙 접근성 개선. 연결된 설원에서 불필요한 트리·링크 다리를 제거하고 북쪽 및 온천 등 필요한 다리는 유지. 22개 산책로를 현재 충돌 모델로 다시 생성.
- 우체국은 접근로 왼쪽(58,20), 정면은 다리에서 오는 방향으로 변경. 스케이트 대여소는 링크 동쪽 출입구 옆(-29,47)으로 이동.
- 회전목마 앞 화단 제거. 산책길 소나무에 금색 가랜드·아이스 블루 세로 조명·민트 리본을 다양하게 배치.
- 스키장 수목 배치 계산의 단위 오류 복구: 반지름(m)에 타원 크기를 중복 곱하던 문제로 모든 나무가 필터링됐다. 185개 후보를 공유 배치·충돌 검사하고, 장식 나무는 별도 조명 묶음으로 관리.
- 성의 여러 첨탑, 지붕·발코니·아치·문장 장식과 흐르는 조명/별가루 강화. 반복 창문을 줄이고 큰 아치와 문장을 섞었다. 관람차 지지대·프레임·곤돌라 조명 복원. 회전목마 크림색 지붕과 따뜻한 조명 강화.
- 더 풍성한 메인 트리 잎, 넓게 물결치는 리본, 여러 층의 작은 전구. 장식은 잎 표면 바깥으로 배치.
- 가로등의 실제 위치에 공통 halo와 눈 반사광을 2개 렌더 묶음으로 적용. 점프 별가루·이동 리본·성의 흐르는 빛을 강화하되 품질 단계와 움직임 줄이기를 유지.
- 자연형 온천: 균일한 둥근 테두리 대신 불규칙한 회색 암석, 눈, 낮은 겨울 관목, 얇은 수증기. 기존 정원 암석에 충돌 영역도 추가하고 통로는 유지.
- 회전목마 카메라는 말과 캐릭터를 함께 보는 사선 구도 및 일정한 초점 높이를 사용. 8개 기둥을 각각 분리해 실제로 가리는 기둥만 탑승 중 반투명 처리하고 하차 후 복구. 1회전 동안 데스크톱/세로 모바일 화면에 말과 탑승자 모두 들어오는지 투영 검사. 지붕·발판의 시간차 별빛도 품질에 따라 24/48/80개로 조절.
- 성의 중앙 장미창, 뾰족한 장식 지붕, 공중 부벽을 추가해 넓은 중앙 벽체를 분절. 보행 아치는 유지.
- 더 작은 원거리 오로라 2개, 가늘고 불균일한 커튼과 느린 파동. 실제 NASA 달 표면 + 날짜별 근사 위상. 배경 설산은 높이를 강화하되 보행 구역은 넓히지 않음.
- 광장·우체국·스키장 눈사람의 머리/얼굴 비율, 짧은 코, 작은 장갑 수정. 손 흔들기, 작은 점프, 몸 들썩임과 상호작용 별가루 추가. 움직임 줄이기에서는 정지 자세 복귀.
- 기본 로딩 스피너와 실제 준비 상태. 작고 가독성 있는 한글 브랜드. 손님 번호 대신 숫자 없는 기본 닉네임.
- 지도·설정·커스터마이징 패널 크기와 투명 재질 통일. 지도는 현재 지형/동선을 반영하고 북쪽 설산은 압축 투영. 선택 표시·모양/색상 버튼·닫기 버튼 정렬 통일.
- 설정/커마/소원 탭의 밑줄·튀어나온 효과 제거, 선택한 탭만 반투명 배경. 음악 선택 영역 폭 복구. 드롭다운은 공통 키보드/터치 선택기로 교체.
- 데스크톱 채팅 입력란은 채팅·감정 아이콘 위에 간격을 두고 배치. 모바일 달리기 토글 추가, 점프를 단순한 도약 신발 실루엣으로 교체. 포인터 소유권을 분리해 이동·카메라·점프를 함께 조작.

## 소원 누락의 원인과 수정

기존 소원 제출은 `lab:wish-draft`만 보내고 창을 닫았다. 실제 저장은 두 번째 트리 클릭이 필요했다. 이제 제출 한 번으로 서버에 장식·소원을 저장하고 확인된 장식을 즉시 렌더링한다. 실패하면 작성 내용을 유지하고, 중복 제출은 막는다. 공개 범위 기본값은 나만 보기다.

선택 색상은 저장돼도 발광색이 공통 금색이어서 구별이 약했다. 인스턴스 색상이 발광에도 적용되도록 수정했다. 처음 빈 트리에서 장식을 추가한 후 선택할 수 있도록 인스턴스 경계도 갱신한다.

미검증: 이 환경에는 실제 브라우저를 조작하는 도구가 없어 WebGL shader의 최종 화면, 모바일 실기기 동시 터치, 실제 두 방문자의 동시 접속은 직접 플레이하지 못했다. DOM/geometry/API 검사는 이를 대신한다고 주장하지 않는다. 미리보기 열기는 화면 검증의 증거로 취급하지 않았다.
