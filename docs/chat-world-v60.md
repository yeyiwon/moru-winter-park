# v60 — 채팅 중 동작 지속과 공동 탑승 안정화

## 확인한 원인과 변경

v59 `park.js`는 `worldInputBlocked()`를 월드 전체의 렌더 중단에도 사용했다. 실제 브라우저에서 채팅 중 1.8초 동안 월드 시간과 렌더 프레임이 모두 고정된 것을 재현했다. 또한 채팅 열기·포커스·키보드 복구에서 발생한 `lab:pause`와 `clear()`가 걷던 경로와 속도를 취소했다.

월드 렌더는 채팅·설정·메뉴와 독립적으로 진행한다. 채팅은 이동 경로·점프·춤·스키·탑승을 취소하지 않는다. 이미 누른 이동키는 놓을 때까지 유효하며 채팅에서 새로 친 글자만 조작 입력으로 받아들이지 않는다. 모바일 키보드 resize에서 조이스틱을 해제하거나 메시지를 전송하고 창을 닫아도 보행 경로는 유지한다. 실제 비활성 탭 절약과 실내 전환 준비는 유지한다.

곤돌라 객실과 탑승자가 각자 `serverNow()`를 읽고, 탑승자는 고정 60Hz 물리 step이 실행될 때만 갱신됐다. 카메라 역시 좌우·높이를 서로 다른 지연으로 따라갔다. 한 화면의 객실·본인·다른 탑승자는 단일 서버 시각을 사용하고 탑승 위치를 표시 프레임마다 갱신한다. 카메라는 차량 이동량을 함께 적용한 뒤 사용자 시점을 보간한다. 노선·운행 속도·서버 예약 규칙은 그대로다.

## 실제 검증

- 기존 정지 재현: [수정 전](../qa/chat-world-v60/before/report.json).
- 입력·탑승·좌석 경쟁·카메라 등 관련 검사 **82/82 PASS**. 새 검사는 곤돌라 전체 운행의 여섯 좌석과 실제 객실 메시를 같은 시각으로 대조한다.
- 실제 PC·390×844 터치 화면: 월드 진행, 본인 입력 경계, 다른 방문자 이동·채팅 수신, 공연, 설정창, 곤돌라, 스키 지속 및 예외 없음 **10/10 PASS**. [결과](../qa/chat-world-v60/after/report.json).
- 최종 채팅 UI·IME·입력 검사 **25/25 PASS**.
- 최종 걷기 경로 유지·키보드 resize·전송 후 경로 유지·이미 누른 이동키·점프 마무리·춤 지속·브라우저 예외 없음 **7/7 PASS**. [결과](../qa/chat-world-v60/motion/report.json).
- 8초·481프레임 곤돌라 측정: 객실/탑승자 최대 오차 **0.0230m→5.86e-14m**, 카메라 상대 높이 범위 **1.681m→2.13e-14m**. 정상까지 실제 95초 운행, 채팅을 연 상태에서 도착 후 하차·좌석 해제, 초급 리프트 실제 도착·하차 확인. [전](../qa/chat-world-v60/ride-before/report.json) · [후](../qa/chat-world-v60/ride-after/report.json).

추가 포레스트 리프트·정상 연결 리프트·관람차·회전목마의 실제 탑승·하차 **4/4 PASS**, 예외 없음. [원본](../qa/chat-world-v60/ride-other-rides/report.json).

검증 스크립트의 자동 닫힘 입력창·출발 후 숨겨진 버튼·별도 시설 목록 선택자 오류로 중단된 실행은 `attempt-*` 및 해당 실행의 failure에 남겼다. 통과 항목을 숨기거나 실패 실행 전체를 성공으로 표기하지 않는다. 후속 개별 실행 결과를 함께 기록한다.

## 범위와 한계

Mac Chrome의 실제 WebGL과 모바일 화면·터치 에뮬레이션이다. 실물 Windows/Galaxy/iPhone 키보드·장시간 발열은 UNKNOWN. 위 수치는 해당 시야·운행 구간의 기능 확인이며 무지연·고정 FPS 보장이 아니다. 정지 화면보다 GPU 작업은 늘지만 새 geometry·texture·shader는 추가하지 않고 기존 품질 예산·배칭을 사용한다.

새 dependency, DB migration, 운영 데이터 삭제, 음원·로딩 자산 변경은 없다. 기존 Cloudflare 실시간 서버의 코드와 데이터는 유지하고 Vercel 화면 및 Sites에 포함된 화면 아티팩트를 갱신한다.
