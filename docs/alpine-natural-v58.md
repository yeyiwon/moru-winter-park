# v58 — 자연스러운 설산·탑승 경로와 꾸미기 확장

2026-11-20. v56/v57 작업에 이어진 사용자 요청이다. 운영 배포 전 검증 중이며 운영 반영 여부는 DEPLOYMENT의 실제 결과를 따른다.

## 지형 원인과 수정

정상 평탄화가 900m 높이를 출발점에서 약 230m 아래까지 유지한 뒤, 코스 폭 바로 밖 28m에서만 원래 높이로 복원됐다. 그래서 정상 출발 후 코스 양옆이 최대 **51.09m** 높은 협곡이 됐다. 별도의 고주파 노이즈가 원인은 아니었다. 산 외곽을 65m 이내에서 지면으로 낮추던 마스크도 평평한 상단과 가파른 벽을 만들었다.

`mountain-layout.js`는 코스망이 놓인 능선과 외곽 사면을 구분한다. 승강장 바닥은 평평하게 유지하되 하류 방향으로는 본래 사면의 높이에 연결하고, 110m 어깨 구간에서 코스와 접한다. 외곽은 코스마다 잘라내지 않고 이어진 넓은 사면으로 낮아진다. 코스 밖에는 저주파 굴곡 두 개만 사용하며 정상 높이를 넘는 봉우리는 만들지 않는다. 마지막 코스의 발동 구간도 보간해 새 가로 단절을 막는다.

정상 이후 240m, 코스 중심 좌우 100m 표본에서 높은 벽은 **51.09→5.44m**로 감소했다. 좌우 65m의 정비 구역·어깨는 급격한 횡경사 없이 이어진다. 정상 준비 공간, 기존 하차장·난간·등·표지, 시설의 XZ 배치와 산의 경계 크기를 보존했다. 중간 환승장은 코스보다 높던 341.856m 기준을 해당 사면의 315.057m로 맞췄다. 최종 코스 연결 뒤에도 승강장 평탄면을 보존하고 코스 밖 28m에서 자연스럽게 잇는다. 외곽 설산 전체를 평지처럼 만들지는 않는다.

주행 중심선·경사·점프 우회는 유지했다. 마지막 요청에 따라 local Z −244m의 평탄한 도착 구역에서 자동 제동하며 −200m 이전에 종료한다. 최고 속도도 남은 정지 거리에 맞춰 감속하므로 시설 앞까지 미끄러지지 않는다. 종료 시 장비·주행 UI를 정리하고 보행으로 복귀한다. 착용 시 10Hz 근접 판정의 오래된 위치를 사용해 되돌아가던 문제는 실제 캐릭터 위치를 사용해 수정했다. 바닥 메시, 지도, 이동 판정, 시설·나무 높이는 같은 높이 함수를 참조한다. 눈 벽을 화면에서만 숨기거나 충돌 높이를 따로 두지 않았다.

## 리프트·곤돌라

수평 경로는 네 노선 모두 직선이다. 기존 리프트는 지형 높이에 22m 여유를 더한 다음 승강장 높이로 복귀하면서 각각 **20.75 / 14.08 / 14.61m** 다시 내려갔다. 이제 약 70m 간격의 제어점을 단조 증가하는 Hermite 곡선으로 연결한다. 양쪽 차선의 지면 간격을 검사하고 부족한 제어점만 올리며 최종 높이를 넘지 않는다. 승강장 직전 상승 후 하강은 네 노선 모두 0m다.

운행 시간은 눈꽃 28→35초, 포레스트 46→68초, 정상 연결 38→62초, 곤돌라 65→95초다. 스키 완주 시간과 별개다. 호 길이 기준 속도·출발/도착 감속·6개 좌석 위치 및 서버 검증을 유지한다. 최신 요청으로 승강장 정차 14→5초, 자리 이동 5→1초, 회차 9.5→6초, 전체 루프 212초와 26개 캐빈의 같은 서버 시각을 사용한다. 배차 8.154초, 최악 문 대기 5.654초(기존 약 21초), 최소 캐빈 간격 7.116m를 전 주기로 확인했다. PC와 터치 두 방문자는 실제 클릭 후 977ms에 같은 캐빈의 다른 좌석을 예약하고 정상까지 동승·채팅·하차했다.

실제 렌더러가 공유된 `gondolaSupports`를 무시하고 케이블 표본마다 별도 기둥을 만들던 원인을 수정했다. 표시되는 기둥은 코스 전체 폭에서 7m 이상 벗어난 공유 위치만 사용한다. 슬로프로 가는 동선을 가로막는 지지기둥이 사라지고 불필요한 구조물 수도 줄었다. 시야 버튼·자동 줌은 추가하지 않았고 마우스·터치 회전과 하차 시 카메라 복귀를 유지한다.

## 비용과 검증

원거리 정비 코스 주변의 기본 격자를 32→24로 줄였다. 가까운 40/저사양 24 격자, 공통 경계 정점, 근거리 25+3/저사양 9+3 청크 상한, worker 생성, 나무 인스턴싱과 자원 해제를 유지한다. 정점별 임시 Vector3/Color 생성을 없애고 같은 수식의 스칼라 계산을 사용한다. 지형 최적화는 재질 색을 바꾸지 않는다. UI는 별도의 명시적 요청대로 공통 반투명 토큰과 선택형 다크모드를 적용했다.

동일한 9개 원거리 청크를 생성한 Node 표본에서 정점 **12,663→8,487**, 삼각형 **22,428→14,076**, 중앙 생성 시간 **126.00→51.48ms**였다. GPU 시간이나 전체 월드 로딩 시간으로 해석하지 않는다. 원본은 `qa/mountain-v58/metrics.json`이다. 정상부터 하단·탑승·성 광장까지 11개 실제 브라우저 화면과 프레임 표본, 실제 활강은 `qa/mountain-v58`에 저장한다. 실제 Windows/Galaxy 기기 시험은 UNKNOWN이다.

## 불꽃놀이 최종 방향

금빛 교차 분출과 반복 나선 패턴을 제거했다. 회전은 각 전체 공연 68% 이후 하이라이트의 **중간 높이 좌우 한 쌍, 한 장면**뿐이다. 아래에서 솟는 분수 불꽃은 회전하지 않는다. 덩어리처럼 보이던 실험적 연기 효과는 사용자 요청에 따라 완전히 제거했다. 뜬금없는 단독 하트는 전체 악보에서 제거했다. 마지막 문장은 0.4초 동안 함께 피어나고 0.75초부터 흩어져 총 2.8초 안에 함께 사라진다. 모든 이용자는 동일한 서버 시각과 seed를 사용한다. 신청 대기는 5초다.

불꽃은 고정 입자 풀을 유지하며 매 프레임 재패킹하지 않는다. 발사/소멸/품질 변경/시각 이동 시에만 배열을 갱신하고 그 사이 움직임은 기존 GPU 계산을 쓴다.

## 부스·설정·커마

- 솜사탕·팝콘·아이스크림·스파클러 부스 제목을 통일했다. 단일 버튼과 제목이 같을 때 제목을 숨기던 원인을 고쳤다.
- 설정·채팅·꾸미기·퀴즈·지식집·활동·음악·상호작용은 공통 아이스 화이트/실버/연한 블루 토큰을 쓴다. 78~82% 패널, 18px 설정 블러, 진한 본문·보조 글씨를 사용한다. 선택형 다크모드는 UI만 바꾸며 월드의 밤/낮·색·조명에는 영향이 없다. 설정은 새로고침 후 유지된다.
- 게스트에게 초대·관리자 로그인 탭을 표시하지 않는다. 소유자는 기존 `/admin` 인증 경로를 쓴다. 관리 기능의 서버 권한 검증은 유지한다.
- 조명 기본은 4번 복숭아색 `#ffd5a1`. 보라·장미·민트·복숭아·파랑 5개가 129개 대상의 실제 색으로 적용되며 월드 시간은 그대로다.
- 새 카탈로그 11종: 머리 7종(트리 요정 별·작은 트리·마녀·호박·유령·루돌프 뿔·별밤 마법사), 음향 3종(이어폰·실버 헤드셋·고양이 헤드셋), 발광 코. 앞머리와 버섯 모자는 제거했다. 머리 장식과 귀를 덮는 헤드셋은 마지막 선택 하나만 착용한다. 이어폰과 코는 독립적으로 조합한다.
- 마녀/마법사 모자는 굽은 주름 원뿔, 두께가 있는 챙, 띠·버클·별 장식으로 구성했다. 호박은 9개 골과 줄기·잎·덩굴·입체 표면을 따른 얼굴, 루돌프는 어두운 갈색 가지 뿔과 결을 사용한다.
- 별 모자는 볼륨 있는 앞뒤 면과 흰 중심을 만들고 갈색 받침은 제거했다. 작은 트리의 18개 전구·꼭대기 별이 빛난다. 은왕관은 금속광과 테이블/크라운/거들/파빌리온이 있는 다이아몬드·받침·반짝임을 사용한다.
- 고양이 귀 밑면은 헤드밴드 곡면에 붙고 양쪽 커진 이어컵·패드·힌지·테두리로 연결된다. 발광 코는 둥근 광택 전구와 흰 반사점·곡선 반사광·부드러운 주변 광륜을 갖는다. 빨강/분홍/보라/파랑/민트/금색이 24초 주기로 부드럽게 전환하며 효과 줄이기에서는 빨강으로 고정한다.
- 액세서리별 25,000정점·재질 그룹 4개 이내, 공통 geometry/material을 재사용한다. 코·트리 광륜은 Points 한 배치이며 추가 PointLight는 없다. 클로즈업에서도 코와 전구의 입체 메시를 유지한다.
- 실제 PC/412×915 DPR3 터치 화면의 장식 정면·측면, 저장·복원, 배타 선택, 메뉴 경계, 낮/밤 및 다크/라이트를 확인했다. `qa/wardrobe-v58`, `qa/interface-v58` 참조. 토큰 배경 합성 대비 16건은 모두 4.5 이상이며 모든 실제 픽셀의 WCAG 인증을 뜻하지 않는다.

## 실제 활강과 화면 비교

동일한 자동 조향의 실제 정상 활강은 수정 전 **61.895초**, 수정 후 **58.005초**였다. 이 수치는 마지막 자동 종료 구역 수정 이전 측정이다. 다섯 중심선 길이와 경사는 그대로이며 프레임 처리·조향 표본에 따른 차이로 약 1분 경험을 유지한다. 변경 후 3,405프레임의 평균 58.70FPS, p95 16.8ms, 상주 청크 최대 28, 하단 보행 복귀와 스키·보드 점프/착지 통과. PC 11시점과 412×915 DPR3 터치 화면 11시점은 모두 브라우저 오류 없이 완료했다. 모바일은 실물 시험이 아니다. 전후 일부 화면의 낮/밤 상태는 자동 시각 설정 때문에 다르므로 색감 비교 근거로 쓰지 않는다.

최종 자동 종료 포함 실제 활강은 **57.592초**, **59.99FPS**, p95 **16.8ms**였다. 하단 world Z −116.436m에서 속도 0·주행 mode 해제로 보행에 복귀했다. 스키/보드 점프와 착지도 다시 통과했다. 원본: `qa/final-v58/descent/desktop-descent-final.json`. 마지막 중간 승강장 연결을 PC·터치 화면에서 재검사해 모두 약 60.1FPS, 지형 상주 27개, 브라우저 오류 0을 확인했다. 최종 동승 측정은 PC 60.12FPS / 모바일 화면 60.11FPS, 정상 하차 뒤 넓은 시야 55.85FPS(p95 33.3ms)이며 실물 모바일 성능을 의미하지 않는다.
