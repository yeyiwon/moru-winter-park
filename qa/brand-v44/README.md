# Name and type study — 2026-11-19

사용자가 SNOWHERE 이름과 세리프 조합을 거절한 뒤 만든 비교 시안이다. 최종 이름 선택이나 운영 반영을 뜻하지 않는다.

- 후보: snowfall / winter hours / winterlight
- 공통: 기존 로딩 트리 원본 경로, 작은 무광 아이보리 심볼, Pretendard 350 소문자. 금빛 블러·큰 대문자·한글 부제 없음.
- 글자: 프로젝트에 포함된 PretendardVariable을 경로로 변환해 렌더링 차이를 제거했다.
- SVG와 PNG는 이름의 분위기와 비율을 비교하기 위한 검토용 자산이다.
- 기존 SNOWHERE 소스는 저장본이며 Sites/Vercel에는 아직 배포하지 않았다. 공개 GitHub 업로드는 자동 승인 검토에서 명시적인 공개 소스 업로드 동의가 없다는 이유로 거절되어 진행하지 않았다. 사용자가 기존 시안을 수정 요청했으므로 배포를 재시도하지 않는다.
